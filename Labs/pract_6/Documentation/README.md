# Практична робота № 6
## Робота з 10-розрядним АЦП мікроконтролера PIC16F877A

### Мета роботи

Навчитися використовувати вбудований 10-розрядний аналого-цифровий перетворювач мікроконтролера PIC16F877A, налаштовувати його регістри керування, зчитувати результат перетворення аналогового сигналу та виводити отриманий цифровий код на світлодіоди.

### Завдання роботи

1. Розробити програму для роботи з 10-розрядним АЦП мікроконтролера PIC16F877A.
2. Налаштувати порти мікроконтролера відповідно до принципової схеми.
3. Організувати вимірювання аналогового сигналу на вході RA0/AN0.
4. Забезпечити безперервне виконання аналого-цифрового перетворення.
5. Виводити результат вимірювання на світлодіоди через порти B та C.

### Теоретичні відомості

Аналого-цифровий перетворювач (АЦП) призначений для перетворення аналогового сигналу в цифровий код. Він дає змогу мікроконтролеру обробляти сигнали від датчиків та інших аналогових пристроїв.

Мікроконтролер PIC16F877A має вбудований 10-розрядний АЦП із вісьмома аналоговими каналами. У цій роботі використовується канал RA0/AN0.

Кількість можливих цифрових значень 10-розрядного АЦП становить:

\[
2^{10}=1024
\]

Отже, результат перетворення може змінюватися від 0 до 1023.

Для діапазону вхідної напруги від 0 до 5 В приблизна напруга одного кроку перетворення становить:

\[
\Delta U=\frac{5}{1024}\approx0{,}00488\text{ В}
\]

Для керування АЦП використовуються регістри ADCON0 та ADCON1. У першому вибирається канал, частота тактування та вмикається перетворювач. Другий використовується для налаштування аналогових входів, опорних напруг і формату результату.

Результат вимірювання зберігається у двох регістрах: ADRESH та ADRESL. Після завершення перетворення їхні значення об'єднуються в одне 10-розрядне число.

### Хід виконання роботи

1. Створено проєкт для мікроконтролера PIC16F877A.
2. Налаштовано порт RA0 як аналоговий вхід, а PORTB і виводи RC0–RC1 — як цифрові виходи.
3. Виконано початкове налаштування регістрів ADCON0 та ADCON1.
4. Реалізовано запуск аналого-цифрового перетворення та очікування його завершення.
5. Організовано зчитування результату з регістрів ADRESH і ADRESL.
6. Реалізовано виведення молодших восьми бітів результату на PORTB, а двох старших бітів — на RC0 та RC1.
7. Передбачено безперервне повторення вимірювання в нескінченному циклі програми.

### Результати роботи

У результаті розроблено програму для безперервного зчитування аналогового сигналу з входу RA0/AN0 мікроконтролера PIC16F877A. Отримане значення АЦП передається на вихідні порти B і C для відображення за допомогою світлодіодів.

Для перевірки роботи необхідно змінювати вхідну напругу в межах допустимого діапазону та спостерігати за зміною станів світлодіодів у симуляторі Proteus.

### Відповіді на контрольні питання

**1. З чого складається модуль АЦП?**

Модуль АЦП містить мультиплексор аналогових каналів, пристрій вибірки-зберігання, компаратор, схему послідовного наближення та регістри керування і збереження результату.

**2. Який алгоритм роботи модуля АЦП?**

Спочатку налаштовується аналоговий канал і вмикається АЦП. Після короткої затримки запускається перетворення. Мікроконтролер очікує його завершення, зчитує цифровий результат і використовує його для подальшої обробки.

**3. Як задається тактування АЦП?**

Частота тактування задається бітами ADCS1 і ADCS0 регістра ADCON0. Можна вибрати поділ частоти генератора або внутрішнє джерело RC.

**4. Які регістри використовуються для забезпечення роботи АЦП?**

Для роботи АЦП використовуються ADCON0 і ADCON1 для керування та налаштування, а також ADRESH і ADRESL для збереження результату перетворення.

**5. Як функціонує модуль АЦП у режимі SLEEP?**

Модуль АЦП може виконувати перетворення в режимі SLEEP за умови використання внутрішнього RC-джерела тактування. Після завершення перетворення може сформуватися прапорець переривання; вихід мікроконтролера зі SLEEP залежить від налаштування дозволів переривань.

**6. У яких регістрах зберігається результат АЦ-перетворення?**

Результат зберігається в ADRESH (старша частина) та ADRESL (молодша частина).

**7. Для чого призначений регістр ADCON1?**

ADCON1 налаштовує конфігурацію аналогових і цифрових входів, вибір опорних напруг та вирівнювання результату перетворення.

**8. Як здійснюється запуск АЦ-перетворення?**

Після налаштування і ввімкнення АЦП встановлюється біт GO/DONE у регістрі ADCON0. Після завершення перетворення цей біт автоматично скидається апаратно.

**9. Як виводиться інформація на символьний РКІ для цілої та дробової частини?**

Число спочатку перетворюється на послідовність символів. Цілу та дробову частини можна обчислити окремо й вивести на дисплей як текст. Для відображення дробової частини необхідно правильно виконати перетворення числового значення та врахувати потрібну точність.

### Висновок

Під час виконання практичної роботи розроблено програму керування 10-розрядним АЦП мікроконтролера PIC16F877A. Розглянуто налаштування регістрів ADCON0 та ADCON1, запуск і завершення перетворення, зчитування цифрового результату та його виведення на порти B і C. Отримані знання можна використовувати під час розроблення пристроїв для вимірювання аналогових сигналів від датчиків.
