# Практична робота №8
## Робота з цифровим датчиком температури DS18B20 через протокол 1-Wire

### Мета роботи

Навчитися застосовувати мікроконтролери для схемотехнічних рішень, вивчити особливості протоколу 1-Wire та принцип роботи цифрового датчика температури DS18B20, розробити програму для взаємодії мікроконтролера з датчиком.

### Завдання

1. Опрацювати теоретичний матеріал про протокол 1-Wire та датчик DS18B20.
2. Описати основні функції для роботи з датчиком.
3. Реалізувати передавання трьох байтів у пам’ять SRAM датчика: верхньої межі TH, нижньої межі TL та регістра конфігурації.
4. Розробити програму для запуску вимірювання температури та читання його результату.
5. Підготувати програму для перевірки в середовищі моделювання.

### Теоретичні відомості

**1-Wire** — це протокол послідовного обміну даними, у якому для передавання інформації використовується одна сигнальна лінія та спільний провід землі. Лінія даних повинна мати підтягувальний резистор до позитивного живлення.

Обмін відбувається між ведучим пристроєм і одним або декількома веденими пристроями. Мікроконтролер формує часові інтервали, за допомогою яких передає команди та зчитує дані.

DS18B20 — цифровий датчик температури з діапазоном вимірювання від −55 °C до +125 °C. Він підтримує роздільну здатність 9, 10, 11 або 12 біт. За роздільної здатності 12 біт крок вимірювання становить 0,0625 °C, а максимальний час перетворення — приблизно 750 мс.

Основні операції роботи з DS18B20:

- ініціалізація шини та перевірка присутності датчика;
- передавання команди ROM для вибору пристрою;
- передавання функціональної команди;
- читання або запис даних;
- запуск температурного перетворення та отримання результату.

### Основні функції програми

У програмі реалізовано такі функції:

- `ow_reset()` — формує імпульс скидання та перевіряє наявність датчика на шині.
- `ow_write_bit()` — передає один біт даних.
- `ow_read_bit()` — зчитує один біт із шини.
- `ow_write_byte()` — передає байт молодшим бітом уперед.
- `ow_read_byte()` — приймає байт даних.
- `ds18b20_write_config()` — передає команду запису та три байти налаштувань.
- `ds18b20_read_temperature()` — запускає температурне перетворення та читає два байти результату.

### Хід виконання роботи

Для виконання практичної роботи підготовлено програму мовою C для мікроконтролера PIC16F877A з тактовою частотою 4 МГц. Для обміну з датчиком використовується вивід RB0.

Спочатку в програмі налаштовується лінія даних. Щоб сформувати логічний нуль, вивід мікроконтролера переводиться в режим виходу та встановлюється низький рівень. Для читання даних лінія відпускається шляхом переведення виводу в режим входу. Це дозволяє уникнути конфлікту між мікроконтролером і датчиком.

Після ініціалізації виконується запис налаштувань у SRAM датчика. Команда `0x4E` використовується для запису трьох байтів: TH, TL і регістра конфігурації. У програмі встановлено TH = 125 °C, TL = −55 °C та 12-бітну роздільну здатність.

Для вимірювання температури передається команда `0x44`. Після очікування завершення перетворення передається команда `0xBE`, яка дозволяє прочитати пам’ять датчика. Молодший і старший байти результату об’єднуються в одне 16-бітне значення.

Отримане значення зберігається у змінній `temperature_raw`. Для отримання цілої частини температури виконується ділення сирого значення на 16.

### Лістинг програми

Повний лістинг програми наведено у файлі `main.c`. У ньому реалізовано функції ініціалізації, запису та читання бітів і байтів, налаштування датчика та вимірювання температури.

### Відповіді на контрольні питання

**1. Для чого призначений протокол обміну 1-Wire і які у нього особливості?**

Протокол 1-Wire призначений для послідовного обміну даними між ведучим і веденими пристроями через одну сигнальну лінію. Обмін є асинхронним і напівдуплексним, а передавання даних залежить від часових інтервалів.

**2. Як здійснюється ініціалізація DS18B20?**

Мікроконтролер формує імпульс скидання тривалістю приблизно 480 мкс, після чого відпускає лінію та очікує імпульс присутності від датчика. Наявність цього імпульсу свідчить про відповідь пристрою.

**3. Як формуються слоти запису логічних «1» та «0»?**

Для запису логічної одиниці мікроконтролер коротко утримує лінію на низькому рівні, а потім відпускає її. Для запису логічного нуля лінія утримується на низькому рівні протягом більшої частини часового слота.

**4. Як передати команду DS18B20?**

Спочатку виконують ініціалізацію шини, потім передають команду ROM, наприклад `0xCC` для пропуску ідентифікації за наявності одного датчика. Після цього передають функціональну команду, наприклад `0x44` або `0xBE`.

**5. Як формуються слоти читання DS18B20?**

Мікроконтролер короткочасно встановлює низький рівень, потім відпускає лінію та зчитує її стан. Датчик передає логічний нуль, утримуючи лінію на низькому рівні, або логічну одиницю, відпускаючи її.

**6. Для чого призначений датчик DS18B20?**

DS18B20 призначений для цифрового вимірювання температури. Він перетворює температуру на цифрове значення, яке можна зчитати через інтерфейс 1-Wire.

**7. Які основні вузли DS18B20?**

До основних функціональних вузлів належать інтерфейс 1-Wire, схема температурного перетворення, пам’ять даних і налаштувань, а також засоби перевірки переданих даних.

**8. Скільки ліній необхідно для роботи з DS18B20?**

Для обміну даними потрібна одна сигнальна лінія DQ та спільна земля GND. За звичайного живлення також підключають вивід VDD до джерела живлення.

**9. Як почати температурне перетворення DS18B20?**

Після ініціалізації та команди ROM передають функціональну команду `0x44` — Convert T. Для 12-бітного перетворення необхідно очікувати до 750 мс.

**10. Як зчитати інформацію про температуру з DS18B20?**

Після завершення перетворення повторно ініціалізують шину, передають `0xCC` і `0xBE`, а потім зчитують молодший і старший байти температурного регістра. Два байти об’єднують у 16-бітне значення, яке містить результат вимірювання.

### Висновок

Під час практичної роботи розглянуто принципи роботи протоколу 1-Wire та цифрового датчика температури DS18B20. Розроблено програмні функції для ініціалізації шини, передавання та приймання бітів і байтів, запису конфігурації та читання результату температурного перетворення.
