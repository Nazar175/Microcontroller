# Практична робота №9
## Використання модуля MSSP мікроконтролера PIC16F877A в режимі I²C для роботи з EEPROM 24C16

### Мета роботи

Навчитися використовувати модуль MSSP мікроконтролера PIC16F877A в режимі I²C для обміну даними із зовнішньою енергонезалежною пам’яттю EEPROM 24C16. Ознайомитися з ініціалізацією модуля, передаванням та прийманням байтів, формуванням умов START і STOP, а також виконанням операцій запису й читання пам’яті.

### Завдання

1. Налаштувати мікроконтролер PIC16F877A для роботи з інтерфейсом I²C.
2. Ініціалізувати модуль MSSP у режимі ведучого пристрою зі швидкістю 100 кГц.
3. Реалізувати функції формування START і STOP, передавання байта та приймання даних із підтвердженням ACK або без підтвердження NACK.
4. Реалізувати запис одного байта до EEPROM 24C16 за адресою `00h`.
5. Реалізувати читання байта з EEPROM за заданою адресою.
6. Розглянути принцип обміну даними між мікроконтролером і зовнішньою пам’яттю через двопровідну шину I²C.

### Результати роботи

Під час виконання практичної роботи було розглянуто принцип роботи інтерфейсу I²C та апаратного модуля MSSP мікроконтролера PIC16F877A.

Інтерфейс I²C використовує дві сигнальні лінії:

- **SCL** — лінія тактових імпульсів;
- **SDA** — лінія передавання даних.

Для роботи шини використовуються підтягувальні резистори, які забезпечують високий рівень сигналу в стані очікування. Мікроконтролер працює як ведучий пристрій Master, а EEPROM 24C16 — як ведений пристрій Slave.

Для отримання тактової частоти 100 кГц за частоти генератора 4 МГц значення регістра `SSPADD` розраховується за формулою:

\[
F_{SCL}=\frac{F_{OSC}}{4(SSPADD+1)}
\]

Звідси:

\[
SSPADD=\frac{4000000}{4\cdot100000}-1=9
\]

Отже, до регістра `SSPADD` записується значення `9`.

Під час ініціалізації виводи RC3/SCL та RC4/SDA налаштовуються як входи. У регістрі `SSPSTAT` встановлюється біт SMP для стандартного режиму швидкості, а біт CKE скидається. Регістр `SSPCON` налаштовується на режим ведучого I²C із тактовим сигналом та вмикає модуль MSSP. Глобальні переривання вимикаються.

Для взаємодії з EEPROM було передбачено такі операції:

1. Формування умови START для початку обміну.
2. Передавання адреси пристрою та адреси комірки пам’яті.
3. Передавання байта даних під час запису.
4. Повторний START для переходу до читання.
5. Приймання байта даних із формуванням ACK або NACK.
6. Формування умови STOP для завершення обміну.

Для перевірки роботи програми використовується запис тестового значення `5Ah` за адресою `00h` із подальшим читанням цієї комірки. Змінну з отриманим значенням можна перевірити у відладчику MPLAB.

Лістинг програми наведено в окремому файлі `main.c`.

### Відповіді на контрольні питання

**1. Для чого призначений модуль MSSP?**

Модуль MSSP (Master Synchronous Serial Port) призначений для синхронного послідовного обміну даними між мікроконтролером і периферійними пристроями. Він підтримує два режими роботи: SPI та I²C. У цій практичній роботі MSSP використовується для взаємодії з EEPROM 24C16.

**2. Які особливості режиму I²C?**

I²C використовує дві сигнальні лінії — SDA для даних і SCL для тактових імпульсів. До однієї шини можна підключати декілька пристроїв, кожен з яких має адресу. Обмін контролює ведучий пристрій, а приймання кожного байта супроводжується бітом підтвердження ACK або відсутності підтвердження NACK.

**3. Як здійснюється формування START і STOP?**

Умова START формується переходом SDA з високого рівня в низький, коли SCL перебуває у високому стані. Для цього в режимі ведучого встановлюється біт SEN у регістрі `SSPCON2`.

Умова STOP формується переходом SDA з низького рівня у високий, коли SCL перебуває у високому стані. Для цього встановлюється біт PEN регістра `SSPCON2`.

**4. Які регістри використовуються для роботи модуля MSSP у режимі I²C?**

Основними регістрами є:

- `SSPCON` — керування режимом роботи та ввімкненням модуля;
- `SSPCON2` — керування START, STOP, повторним START, прийманням і підтвердженням;
- `SSPSTAT` — регістр стану обміну;
- `SSPBUF` — буфер передавання та приймання даних;
- `SSPADD` — регістр налаштування тактової частоти в режимі Master;
- `SSPSR` — внутрішній регістр зсуву.

**5. Поясніть призначення регістра SSPSR.**

Регістр SSPSR є внутрішнім регістром зсуву модуля MSSP. Він забезпечує послідовне передавання бітів під час передавання байта та послідовне приймання бітів під час отримання даних. Користувач безпосередньо не має доступу до цього регістра. Після завершення приймання байт передається до буфера `SSPBUF`.

### Висновок

Під час практичної роботи було розглянуто принципи роботи шини I²C та особливості використання модуля MSSP мікроконтролера PIC16F877A. Визначено значення регістра `SSPADD` для швидкості 100 кГц, розглянуто налаштування керувальних регістрів і створено програмні функції для передавання та приймання даних. Також розроблено фрагменти програми для запису тестового байта до EEPROM 24C16 та його подальшого читання.
