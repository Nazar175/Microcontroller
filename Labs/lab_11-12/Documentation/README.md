# Звіт до лабораторної роботи №11–12
## Тема: Програмування модуля UART/USART мікроконтролера

### Мета роботи

Навчитися застосовувати мікроконтролери для схемотехнічних рішень, налаштовувати модуль USART в асинхронному режимі та виконувати передавання й приймання інформації між мікроконтролером і комп’ютерним терміналом.

### Завдання роботи

1. Написати програму для роботи модуля USART в асинхронному режимі.
2. Виконати ініціалізацію портів мікроконтролера та модуля USART.
3. Налаштувати термінал на швидкість 9600 біт/с, 8 біт даних, без біта парності та з одним стоповим бітом.
4. Реалізувати передавання символів власного імені за допомогою кодів ASCII.
5. Реалізувати приймання символів із термінала.
6. Реалізувати відображення введених символів за допомогою функції Echo.
7. Реалізувати передавання отриманих символів у вихідний термінал.

### Теоретичні відомості

UART — це універсальний асинхронний приймач-передавач, призначений для послідовного обміну даними між пристроями. Модуль USART мікроконтролера може працювати в асинхронному та синхронному режимах.

Під час асинхронного передавання окремий тактовий сигнал між пристроями не передається. Для визначення меж байта використовуються стартовий і стоповий біти. У цій роботі використовується формат передавання 8N1: один стартовий біт, 8 біт даних, відсутність біта парності та один стоповий біт.

Для налаштування USART мікроконтролера PIC16F877A використовуються такі регістри:

- **TXSTA** — керування та контроль передавача.
- **RCSTA** — керування та контроль приймача.
- **SPBRG** — встановлення швидкості обміну.
- **TXREG** — регістр даних для передавання.
- **RCREG** — регістр отриманих даних.

Для асинхронного обміну необхідно ввімкнути передавач і приймач, вибрати відповідну швидкість та налаштувати виводи RC6/TX і RC7/RX.

### Розрахунок швидкості обміну

Для прикладу використано мікроконтролер PIC16F877A з тактовою частотою \(F_{OSC}=4\text{ МГц}\). Для асинхронного режиму з високою швидкістю передавання використовується формула:

\[
V=\frac{F_{OSC}}{16(X+1)}
\]

де \(X\) — значення регістра SPBRG.

Для швидкості 9600 біт/с:

\[
X=\frac{4\,000\,000}{16\cdot9600}-1\approx25.04
\]

Вибираємо ціле значення \(X=25\). Фактична швидкість становить:

\[
V=\frac{4\,000\,000}{16(25+1)}
\approx9615\text{ біт/с}
\]

Похибка швидкості становить приблизно 0,16 %, що є прийнятним для цього прикладу.

Тривалість передавання одного біта при швидкості 9600 біт/с:

\[
T=\frac{1}{9600}\approx104.17\text{ мкс}
\]

### Хід виконання роботи

**1. Ініціалізація мікроконтролера**

Було налаштовано виводи RC6 і RC7 для роботи передавача та приймача USART. Модуль працює в асинхронному режимі з 8-бітними даними. Для встановлення швидкості обміну використано регістр SPBRG.

**2. Передавання символів**

Для перевірки передавання програма надсилає в термінал текстове повідомлення та послідовність символів ASCII. Кожний символ передається через регістр TXREG після перевірки готовності передавача.

**3. Приймання даних**

Програма перевіряє наявність отриманих даних у буфері USART. Коли надходить новий символ, його код зчитується з регістра RCREG.

**4. Відображення символів (Echo)**

Після приймання символ передається назад у термінал. Завдяки цьому введені символи можна побачити у вікні Virtual Terminal. Якщо Echo термінала також увімкнено, введений символ може відображатися двічі: один раз самим терміналом, а другий — у відповідь від мікроконтролера.

**5. Передавання даних між терміналами**

Для пересилання даних використовується принцип: символ надходить у приймач мікроконтролера через RC7/RX, після чого програма передає його через RC6/TX до вихідного термінала. Для роботи з двома окремими терміналами їхні з’єднання мають відповідати схемі.

**6. Налаштування Virtual Terminal**

У Proteus для термінала потрібно встановити такі параметри:

- швидкість — 9600 біт/с;
- кількість бітів даних — 8;
- парність — None;
- стопові біти — 1.

Після завантаження HEX-файлу запускається симуляція. У вікні термінала можна перевірити передавання повідомлення та реакцію програми на введені символи.

### Результати роботи

У результаті виконання роботи було розглянуто налаштування модуля USART для асинхронного обміну даними. Підготовлено програму для передавання текстового повідомлення, приймання символів із термінала та їхнього повторного передавання.

Для перевірки роботи необхідно використати Virtual Terminal у Proteus, встановити параметри 9600, 8N1 і перевірити правильність передавання та приймання символів. До звіту додаються скриншоти налаштувань термінала, результату передавання повідомлення та перевірки Echo.

### Відповіді на контрольні питання

**1. Для чого призначений модуль UART?**

UART призначений для послідовного асинхронного передавання та приймання даних між пристроями, наприклад між мікроконтролером і комп’ютерним терміналом.

**2. Які регістри використовуються для роботи модуля USART?**

Основними регістрами є TXSTA, RCSTA, SPBRG, TXREG і RCREG. Вони використовуються для налаштування режиму роботи, швидкості обміну, передавання та приймання даних.

**3. Які особливості асинхронного обміну даними?**

Окремий тактовий сигнал не передається. Для визначення початку та кінця байта використовуються стартовий і стоповий біти. Передавач і приймач повинні використовувати однакові параметри обміну.

**4. Яким чином забезпечується однакова швидкість передавача та приймача?**

Швидкість налаштовується регістром SPBRG і бітом BRGH. На обох пристроях потрібно встановити однакову швидкість, кількість бітів даних, парність і кількість стопових бітів.

**5. Як працює USART в режимі асинхронного передавача?**

Програма записує байт у TXREG. Потім апаратний модуль передає його через регістр зсуву TSR на вивід TX. Передавання відбувається з урахуванням стартового біта, бітів даних і стопового біта.

**6. Як працює USART в режимі асинхронного приймача?**

Приймач визначає стартовий біт, зчитує біти даних і перевіряє стоповий біт. Після приймання байт записується в RCREG, звідки його може прочитати програма.

**7. Як поєднати TTL-рівні UART з рівнями RS-232 ПК?**

Для фізичного з’єднання з класичним інтерфейсом RS-232 застосовують перетворювач рівнів, наприклад MAX232. У цифровій моделі Proteus Virtual Terminal може бути підключений безпосередньо, якщо схема та налаштування полярності це дозволяють.

**8. Як визначити тривалість біта інформації при заданій швидкості в бодах?**

Тривалість одного біта визначається формулою \(T=1/V\), або \(T=10^6/V\) мікросекунд. Для 9600 біт/с тривалість становить приблизно 104,17 мкс.

**9. Для чого призначена функція putch(x)?**

Функція putch(x) передає один символ або байт у вихідний потік. У цій роботі вона може використовуватися для надсилання символів через UART до термінала.

**10. Як передати дані із середовища Proteus у термінал PuTTY?**

Потрібно організувати з’єднання через COM-порт або пару віртуальних COM-портів. Один порт налаштовується в PuTTY, інший — у моделі Proteus через COMPIM. Для обох сторін задаються однакові параметри обміну, наприклад 9600, 8N1.

**11. Для чого використовуються ESC-послідовності?**

ESC-послідовності використовуються для керування відображенням у терміналі: очищення екрана, переміщення курсора, зміни атрибутів і кольорів тексту. Зазвичай вони починаються з керуючого символу ESC.
