# Практична робота № 1
## Конфігурування мікроконтролера PIC16F84A та основи програмування

### Мета роботи

Навчитися працювати з регістром конфігурації мікроконтролера PIC16F84A. Закріпити знання синтаксису написання програм у середовищі MPLAB, ознайомитися з налаштуванням конфігураційних бітів та структурою програми мовою C.

### Завдання роботи

1. Вивчити призначення регістра конфігурації мікроконтролера.
2. Ознайомитися із синтаксисом написання програм для MPASM та HI-TECH PICC.
3. Виконати налаштування бітів конфігурації для заданих варіантів.
4. Задати конфігураційні біти за допомогою директиви CONFIG для MPASM.
5. Задати конфігураційні біти за допомогою макросу CONFIG для HI-TECH PICC.
6. Написати програму мовою C для PIC16F84A з оголошенням змінних TMP1, TMP2 та функції SUM.
7. Реалізувати ініціалізацію змінних і постійний виклик функції SUM у робочому циклі.

### Теоретичні відомості

Мікроконтролер PIC16F84A має регістр конфігурації, який використовується для визначення початкових параметрів його роботи. За допомогою конфігураційних бітів можна вибрати тип тактового генератора, увімкнути або вимкнути сторожовий таймер, налаштувати затримку запуску після ввімкнення живлення та встановити захист пам'яті програм.

Регістри мікроконтролера є спеціальними комірками пам'яті, призначеними для зберігання даних і керування роботою внутрішніх пристроїв. Правильне налаштування конфігурації є важливою умовою коректної роботи мікроконтролера.

У PIC16F84A конфігураційні біти розміщені за адресою 2007h. Ця адреса знаходиться поза межами звичайної користувацької пам'яті програм. Налаштування виконується під час програмування мікроконтролера.

Основні параметри конфігурації:

- **CP** — захист пам'яті програм.
- **PWRT** — таймер затримки запуску після ввімкнення живлення.
- **WDT** — сторожовий таймер, який допомагає відновити роботу пристрою в разі зависання програми.
- **FOSC** — вибір типу тактового генератора.

Для запису конфігурації в асемблері MPASM використовується директива CONFIG. У середовищі HI-TECH PICC параметри задаються за допомогою макросу CONFIG після підключення відповідного заголовкового файлу.

### Хід виконання роботи

#### Вивчення регістра конфігурації

Під час виконання роботи було розглянуто призначення регістра конфігурації PIC16F84A та параметри, які він визначає. Було встановлено, що конфігураційні біти впливають на режим роботи тактового генератора, запуск мікроконтролера, роботу сторожового таймера та захист програми.

#### Налаштування конфігураційних бітів

За методичними вказівками розглянуто два варіанти конфігурації.

**Варіант 1:**

- захист коду вимкнений;
- таймер запуску живлення увімкнений;
- сторожовий таймер увімкнений;
- вибраний XT-генератор.

**Варіант 2:**

- захист коду увімкнений;
- таймер запуску живлення вимкнений;
- сторожовий таймер вимкнений;
- вибраний RC-генератор.

Для запису параметрів розглянуто використання директиви CONFIG у MPASM і відповідного макросу CONFIG у HI-TECH PICC.

#### Створення програми мовою C

Було підготовлено програму для PIC16F84A, яка містить заголовковий файл підтримки мікроконтролера, конфігураційний макрос, оголошення змінних TMP1 і TMP2 та функцію SUM.

У програмі виконуються такі дії:

1. Підключається заголовковий файл `pic.h`.
2. Задаються параметри конфігурації мікроконтролера.
3. Оголошуються змінні TMP1, TMP2 та змінна для збереження результату.
4. Оголошується і визначається функція SUM, яка повертає суму двох змінних.
5. У головній функції `main()` виконується початкова ініціалізація змінних.
6. У нескінченному циклі постійно викликається функція SUM.

Для перевірки алгоритму використано значення TMP1 = 5 і TMP2 = 3. Результатом додавання є число 8, яке зберігається у змінній RESULT.

#### Особливості структури програми

Програма складається з кількох основних частин: підключення заголовкових файлів, налаштування конфігурації, оголошення змінних, опис функцій та основної програми.

Для постійного виконання команд використовується цикл `while (1)`. Такий підхід часто застосовується у програмах для мікроконтролерів, оскільки пристрій повинен безперервно виконувати заданий алгоритм.

#### Підготовка до компіляції

Вихідний код збережено у файлі `main.c`. Для отримання HEX-файлу необхідно використати сумісний компілятор HI-TECH PICC та правильно налаштувати проєкт для PIC16F84A.

Під час компіляції слід перевірити правильність синтаксису макросу CONFIG, наявність необхідних конфігураційних констант і відсутність помилок у програмі.

### Результати роботи

У результаті опрацювання методичних вказівок було розглянуто призначення регістра конфігурації PIC16F84A та основні конфігураційні біти. Вивчено відмінності між налаштуванням конфігурації в MPASM та HI-TECH PICC.

Також було підготовлено приклад програми мовою C зі змінними TMP1 і TMP2 та функцією SUM. Програма демонструє ініціалізацію змінних, обчислення суми та постійне виконання функції в робочому циклі.

### Відповіді на контрольні питання

**1. Для чого призначені регістри?**

Регістри — це комірки пам'яті всередині мікроконтролера, які використовуються для зберігання даних, проміжних результатів обчислень і керування внутрішніми пристроями. Обмін інформацією між регістрами здійснюється за допомогою команд програми.

**2. Для чого призначений регістр CONFIG? За якою адресою він знаходиться? Чи можна зчитати його вміст?**

Регістр CONFIG призначений для зберігання конфігураційних бітів, що визначають початкові режими роботи мікроконтролера. У PIC16F84A він розташований за адресою 2007h. Ця адреса перебуває поза межами звичайної користувацької пам'яті програм. Доступ до конфігураційного слова здійснюється в режимі програмування мікроконтролера; це не звичайний регістр, який можна читати під час виконання користувацької програми стандартними командами.

**3. Як відбувається редагування макросу CONFIG?**

Макрос CONFIG редагується шляхом зазначення необхідних параметрів конфігурації відповідно до документації на мікроконтролер і компілятор. У HI-TECH PICC потрібні константи поєднуються за допомогою оператора `&`. У MPASM використовується директива CONFIG із відповідним значенням конфігураційного слова.

**4. Яка структура програми в середовищі MPLAB?**

Програма зазвичай складається із заголовкової частини, робочої частини та завершальної частини. У програмі мовою C заголовкова частина містить директиви підключення файлів і конфігурацію, далі розташовуються оголошення змінних і функцій, а потім основна функція `main()` із робочим циклом.

**5. Що розміщується у заголовку програми?**

У заголовку програми розміщуються директиви підключення заголовкових файлів, параметри конфігурації, оголошення констант і змінних, а також прототипи функцій. Для асемблерних програм додатково можуть задаватися символічні імена регістрів, бітів та інших ресурсів мікроконтролера.

**6. Яке призначення файлу pic.h?**

Файл `pic.h` містить опис засобів підтримки мікроконтролерів PIC, зокрема символічні імена регістрів, конфігураційних констант та інші визначення, необхідні компілятору. Він дає змогу використовувати в програмі зрозумілі назви замість безпосередніх адрес регістрів. У конкретній версії компілятора склад і спосіб підключення цього файлу можуть відрізнятися.

**7. Що записується у робочій частині програми?**

У робочій частині програми записуються команди, які реалізують необхідний алгоритм: обробку даних, обчислення, перевірки умов, роботу з портами та виклики функцій. У цій роботі робоча частина містить постійний виклик функції SUM.

**8. Який оператор мови C реалізує конструкцію робочої частини програми?**

Для організації нескінченного робочого циклу використовується оператор `while (1)`. Умова `1` завжди є істинною, тому цикл виконується постійно, доки роботу мікроконтролера не буде зупинено або перезапущено.
