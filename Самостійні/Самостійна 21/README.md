# Самостійна робота №21

**Тема:** Використання директив, шаблон-заготовка програми та основні функції компілятора.

## Контрольні питання до лекції 21

### 1. Особливості використання директив

Директиви — це спеціальні вказівки, які використовуються під час написання та компіляції програми. Вони допомагають налаштовувати процес компіляції, визначати структуру програми, задавати константи, підключати додаткові файли та організовувати розміщення даних у пам'яті мікроконтролера.

На відміну від звичайних команд, директиви не виконуються безпосередньо мікроконтролером. Вони призначені для компілятора або асемблера.

Основні особливості використання директив:

- **Визначення констант.** Дозволяють задавати постійні значення, які можна використовувати в різних частинах програми.
- **Організація пам'яті.** Допомагають визначати адреси розміщення програмного коду та даних.
- **Підключення файлів.** Дозволяють додавати до програми бібліотеки та інші файли з необхідними описами.
- **Керування компіляцією.** Можуть вмикати або вимикати окремі фрагменти коду залежно від заданих умов.
- **Покращення читабельності.** Допомагають зробити програму зрозумілішою та зручнішою для редагування.

Приклади директив, які використовуються в асемблері PIC:

| Директива | Призначення |
|---|---|
| `ORG` | Визначає адресу початку розміщення коду або даних |
| `EQU` | Призначає символічне ім'я певному значенню |
| `END` | Позначає завершення вихідного файлу |
| `LIST` | Вказує параметри формування лістингу |
| `INCLUDE` | Підключає інший файл до програми |
| `CBLOCK` | Організовує послідовне визначення адрес змінних |
| `ENDC` | Завершує блок, створений директивою `CBLOCK` |

Приклад використання директив:

```asm
STATUS  EQU  03h
PORTA   EQU  05h

        ORG  0x0000

START:
        ; Основна частина програми

        END
```

У цьому прикладі директива `EQU` задає символічні назви для адрес, `ORG` визначає початкову адресу програми, а `END` позначає її завершення.

Отже, директиви є важливою частиною розробки програм для мікроконтролерів, оскільки спрощують написання коду, допомагають організувати його структуру та правильно підготувати програму до компіляції.

### 2. Шаблон-заготовка програми

Шаблон-заготовка програми — це стандартна початкова структура вихідного коду, яка використовується як основа для створення нових програм. Вона містить основні елементи, необхідні для правильної організації коду, налаштування мікроконтролера та подальшої роботи з ним.

Використання шаблону дозволяє не створювати структуру програми з нуля щоразу, а одразу переходити до реалізації потрібного алгоритму.

Типова заготовка програми для мікроконтролера PIC може містити такі частини:

1. **Заголовок програми** — назва, автор, дата та короткий опис призначення.
2. **Підключення файлів** — додавання заголовків із визначеннями регістрів та інших необхідних даних.
3. **Налаштування мікроконтролера** — визначення параметрів роботи, наприклад тактового генератора та сторожового таймера.
4. **Оголошення констант і змінних** — визначення необхідних адрес, імен та областей пам'яті.
5. **Початкова адреса програми** — визначення точки входу після скидання мікроконтролера.
6. **Ініціалізація** — налаштування портів введення-виведення та інших периферійних пристроїв.
7. **Основний цикл** — виконання головних операцій програми.
8. **Завершальна директива** — позначення кінця вихідного файлу.

Приклад простої заготовки програми на асемблері:

```asm
;--------------------------------
; Назва: Моя перша програма
; Призначення: Шаблон програми PIC
;--------------------------------

        LIST    P=16F84A
        INCLUDE "P16F84A.INC"

; Конфігурація мікроконтролера
        __CONFIG _XT_OSC & _WDT_OFF & _PWRTE_ON

; Оголошення змінних
        CBLOCK  0x0C
            TEMP
        ENDC

; Початкова адреса програми
        ORG     0x0000
        GOTO    START

; Основна програма
START:
        BSF     STATUS, RP0
        CLRF    TRISB
        BCF     STATUS, RP0

MAIN:
        CLRF    PORTB
        GOTO    MAIN

        END
```

У цьому прикладі підключається файл із визначеннями для PIC16F84A, задаються параметри конфігурації, оголошується змінна `TEMP` та налаштовується порт B як вихідний. У головному циклі порт B очищується, після чого програма повторює виконання циклу.

Важливо, що конкретний шаблон залежить від моделі мікроконтролера, середовища розробки та мови програмування. Наприклад, для іншої моделі PIC можуть відрізнятися назви регістрів, директиви конфігурації та підключені файли.

### 3. Основні функції компілятора

Компілятор — це спеціальна програма, яка перетворює вихідний код, написаний мовою програмування високого рівня, наприклад C, у машинний код, зрозумілий мікроконтролеру.

Під час розробки програм для мікроконтролерів компілятор виконує декілька важливих функцій:

1. **Перевірка синтаксису.** Перевіряє правильність написання команд, операторів та конструкцій мови програмування.
2. **Виявлення помилок.** Повідомляє про помилки в коді, наприклад неправильне оголошення змінних або відсутність необхідних символів.
3. **Перетворення коду.** Перекладає вихідний код у машинні інструкції, які може виконувати мікроконтролер.
4. **Оптимізація програми.** За можливості зменшує розмір коду та покращує швидкість його виконання.
5. **Робота з пам'яттю.** Розподіляє змінні та інші дані у доступних областях пам'яті мікроконтролера.
6. **Формування вихідних файлів.** Створює об'єктні файли та інші результати компіляції, які можуть використовуватися під час компонування програми.
7. **Формування повідомлень.** Виводить інформацію про помилки, попередження та успішне завершення компіляції.

Зазвичай процес створення програми для мікроконтролера складається з кількох етапів:

- написання вихідного коду;
- компіляція окремих файлів;
- компонування об'єктних файлів і бібліотек;
- створення кінцевого файлу прошивки, наприклад HEX;
- завантаження програми в пам'ять мікроконтролера.

Для розробки програм PIC можуть використовуватися різні інструменти, зокрема компілятори XC8 та HI-TECH C, а також асемблери. Конкретний набір можливостей залежить від обраного інструмента.

Таким чином, компілятор є важливим інструментом розробки, оскільки забезпечує перетворення програмного коду у формат, придатний для виконання мікроконтролером, а також допомагає знаходити помилки та покращувати програму.

## Висновок

Під час виконання самостійної роботи було розглянуто призначення та особливості використання директив, структуру шаблону-заготовки програми та основні функції компілятора. Було з'ясовано, що директиви допомагають організовувати програмний код і керувати процесом його підготовки, шаблон дозволяє створювати програми на основі готової структури, а компілятор перетворює вихідний код у машинні інструкції. Отримані знання є важливими для подальшої розробки та налагодження програм для мікроконтролерів.
