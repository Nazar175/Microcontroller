# Практична робота №7
## Програмування модуля UART/USART мікроконтролера PIC16F877A

### Мета роботи

Навчитися застосовувати мікроконтролери для схемотехнічних рішень, налаштовувати модуль USART в асинхронному режимі та організовувати передавання і приймання інформації між мікроконтролером і персональним комп’ютером.

### Завдання

1. Написати програму для роботи модуля USART в асинхронному режимі.
2. Виконати ініціалізацію портів мікроконтролера та модуля USART.
3. Реалізувати передавання символів власного імені за допомогою кодів ASCII.
4. Написати фрагмент програми для читання даних із термінала.
5. Реалізувати переадресування прийнятих даних назад у термінал.

### Теоретичні відомості

UART — це універсальний асинхронний приймопередавач, призначений для послідовного обміну даними між електронними пристроями. У мікроконтролері PIC16F877A модуль USART підтримує асинхронний та синхронний режими роботи.

Під час асинхронного передавання кожен байт містить стартовий біт, біти даних і стоповий біт. Для узгодженої роботи пристроїв необхідно встановити однакову швидкість передавання.

Для роботи USART використовуються такі регістри:

- **TXSTA** — керування передавачем.
- **RCSTA** — керування приймачем і модулем USART.
- **SPBRG** — налаштування швидкості обміну.
- **TXREG** — регістр даних передавача.
- **RCREG** — регістр прийнятих даних.

У PIC16F877A для UART використовуються виводи RC6/TX та RC7/RX. Передавач мікроконтролера з'єднується з приймачем іншого пристрою, а приймач — із передавачем.

### Хід виконання роботи

Спочатку було створено програму мовою C для мікроконтролера PIC16F877A. Для роботи використано кварцовий генератор частотою 4 МГц.

У програмі налаштовано порт C: вивід RC6 використовується для передавання даних, а RC7 — для приймання. Регістр SPBRG встановлено у значення 25, що забезпечує швидкість обміну, близьку до 9600 бод.

Регістр TXSTA налаштовано для асинхронного режиму з увімкненим передавачем. Регістр RCSTA забезпечує ввімкнення модуля USART та приймача.

Для передавання тексту створено функцію `uart_send_text()`, яка послідовно надсилає символи рядка. Функція `uart_send_char()` очікує готовності передавача та записує символ у TXREG.

Для приймання даних створено функцію `uart_read_char()`. Вона очікує появи прийнятого символу та зчитує його з RCREG. В основному циклі отриманий символ одразу передається назад у термінал.

Таким чином, програма реалізує передавання текстового повідомлення та приймання з подальшим поверненням введених символів.

### Результати роботи

У результаті розроблено програму для роботи модуля USART мікроконтролера PIC16F877A в асинхронному режимі.

Програма містить налаштування швидкості обміну, передавання текстового повідомлення, приймання символів із термінала та повернення отриманих символів назад.

### Відповіді на контрольні питання

**1. Для чого призначений модуль UART?**

UART призначений для послідовного асинхронного передавання та приймання даних між пристроями, наприклад між мікроконтролером і комп’ютером.

**2. Які регістри використовуються для роботи модуля USART?**

Основними є TXSTA, RCSTA, SPBRG, TXREG і RCREG. Також використовуються прапорці готовності передавача та приймача, зокрема TXIF і RCIF.

**3. Які особливості асинхронного обміну даними?**

Тактовий сигнал окремо не передається. Для визначення меж байта використовуються стартовий і стоповий біти. Передавач і приймач повинні працювати з узгодженою швидкістю та форматом даних.

**4. Яким чином забезпечується однакова швидкість передавача та приймача?**

На обох пристроях встановлюють однакову швидкість обміну. У PIC16F877A вона налаштовується за допомогою регістра SPBRG і біта BRGH регістра TXSTA.

**5. Як працює USART у режимі асинхронного передавача?**

Програма записує байт у TXREG. Потім апаратний передавач формує послідовність зі стартового біта, бітів даних і стопового біта та передає її через вивід TX.

**6. Як працює USART у режимі асинхронного приймача?**

Приймач визначає початок передавання за стартовим бітом, приймає біти даних і перевіряє стоповий біт. Прийнятий байт записується в RCREG, звідки його зчитує програма.

**7. Яким чином можна поєднати TTL-рівні UART із рівнями RS-232 ПК?**

Для фізичного інтерфейсу RS-232 використовують перетворювач рівнів, наприклад MAX232. Він перетворює логічні рівні мікроконтролера на рівні RS-232 і навпаки. У Proteus Virtual Terminal зазвичай можна працювати безпосередньо з логічними сигналами UART.

**8. Як визначити тривалість біта інформації при заданій швидкості в бодах?**

Тривалість біта визначають за формулою:

\[
T=\frac{1}{V}
\]

де \(T\) — тривалість біта в секундах, \(V\) — швидкість передавання в бодах.

Для 9600 бод:

\[
T=\frac{1}{9600}\approx104{,}17\ мкс
\]

**9. Для чого призначена функція putch(x)?**

Функція `putch(x)` передає один символ у вихідний потік даних. У програмі для UART її функціональним аналогом є функція `uart_send_char()`, яка записує символ у регістр TXREG після перевірки готовності передавача.
