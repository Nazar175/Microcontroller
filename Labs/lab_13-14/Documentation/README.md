# Лабораторна робота №13–14
## Робота з цифровим датчиком температури DS18B20 через інтерфейс 1-Wire

### Мета роботи

Навчитися застосовувати мікроконтролери для схемотехнічних рішень, ознайомитися з принципом роботи цифрового датчика температури DS18B20 та навчитися передавати дані через інтерфейс 1-Wire.

### Завдання роботи

1. Опрацювати теоретичні відомості про протокол 1-Wire.
2. Розглянути основні функції для роботи з датчиком DS18B20.
3. Розробити програму для передавання трьох інформаційних байтів у пам’ять датчика: регістр верхньої межі температури TH, регістр нижньої межі TL та регістр конфігурації.
4. Відлагодити та скомпілювати програму в MPLAB.
5. Завантажити файл HEX у мікроконтролер у середовищі Proteus.
6. Перевірити запис даних за адресами `02h`, `03h` та `04h`.

### Індивідуальне завдання

Розробити програму для мікроконтролера PIC16F877A, яка забезпечує обмін даними з цифровим датчиком температури DS18B20 за протоколом 1-Wire.

Для запису використано такі значення:

| Адреса пам’яті | Призначення | Значення |
|---|---|---|
| `02h` | Регістр верхньої температурної межі TH | `7Dh` |
| `03h` | Регістр нижньої температурної межі TL | `C9h` |
| `04h` | Регістр конфігурації | `7Fh` |

Значення `7Dh` відповідає верхній межі +125 °C, `C9h` — нижній межі −55 °C, а `7Fh` задає конфігурацію 12-бітного перетворення температури згідно з методичними вказівками.

### Теоретичні відомості

DS18B20 — це цифровий датчик температури, який передає дані за допомогою інтерфейсу 1-Wire. Він дозволяє вимірювати температуру в діапазоні від −55 °C до +125 °C. Для обміну інформацією достатньо однієї лінії даних і спільного проводу живлення, якщо використовується звичайне зовнішнє живлення.

Протокол 1-Wire передбачає одного ведучого пристрою, яким у цій роботі є мікроконтролер, та одного або декількох ведених пристроїв. Передавання інформації здійснюється через часові інтервали, тому програмне забезпечення повинно точно формувати імпульси.

Для коректної роботи лінія даних підтягується до позитивного живлення резистором приблизно 4,7 кОм. Мікроконтролер формує логічний нуль, утримуючи лінію на низькому рівні, а для логічної одиниці відпускає її. Не можна примусово встановлювати високий рівень виходом мікроконтролера, оскільки це може спричинити конфлікт на шині.

Основні етапи обміну з DS18B20:

1. Формування імпульсу скидання та перевірка присутності датчика.
2. Передавання команди ROM.
3. Передавання функціональної команди.
4. Передавання або читання даних.

Для роботи з одним датчиком можна використати команду `Skip ROM` (`CCh`), яка дозволяє пропустити індивідуальну адресу пристрою. Команда `Write Scratchpad` (`4Eh`) забезпечує запис трьох байтів: TH, TL і конфігурації.

### Основні функції програми

- `ow_reset()` — формує імпульс скидання та перевіряє наявність датчика.
- `ow_write_bit()` — передає один біт через шину 1-Wire.
- `ow_read_bit()` — зчитує один біт із шини.
- `ow_write_byte()` — передає байт, починаючи з молодшого біта.
- `ow_read_byte()` — приймає байт від датчика.
- `ds18b20_write_settings()` — передає команди та записує три байти налаштувань.
- `ds18b20_read_scratchpad()` — читає вміст пам’яті датчика для перевірки запису.

### Порядок виконання роботи

1. У MPLAB створено проєкт для мікроконтролера PIC16F877A.
2. Налаштовано частоту кварцового резонатора 4 МГц та лінію RB0 для роботи з шиною 1-Wire.
3. Реалізовано програмні функції формування імпульсів скидання, запису та читання бітів.
4. У програмі передбачено передавання команди `Skip ROM` та команди `Write Scratchpad`.
5. Передано значення `7Dh`, `C9h` і `7Fh` у відповідні регістри пам’яті датчика.
6. Для перевірки передбачено читання пам’яті командою `Read Scratchpad`.
7. Після компіляції програми отриманий HEX-файл використано в моделі Proteus для перевірки обміну даними.

### Перевірка результатів

Після виконання запису необхідно перевірити значення трьох байтів у пам’яті DS18B20. Для цього передбачено повторну ініціалізацію шини, передавання команд `Skip ROM` і `Read Scratchpad`, а потім читання перших п’яти байтів пам’яті.

Очікувані значення:

| Адреса | Очікуване значення |
|---|---|
| `02h` | `7Dh` |
| `03h` | `C9h` |
| `04h` | `7Fh` |

Фактичне підтвердження результату потрібно виконати у Proteus після запуску симуляції. Якщо значення не збігаються з очікуваними, необхідно перевірити підключення лінії DQ, підтягувальний резистор, частоту мікроконтролера та часові інтервали протоколу.

### Відповіді на контрольні питання

**1. Для чого призначений датчик DS18B20?**

DS18B20 призначений для вимірювання температури та передавання цифрового результату мікроконтролеру через інтерфейс 1-Wire.

**2. Які основні вузли DS18B20?**

Основними вузлами є температурний перетворювач, пам’ять даних, блок керування, інтерфейс 1-Wire та постійний 64-бітний код ROM.

**3. Як здійснюється живлення DS18B20?**

Датчик може живитися від зовнішнього джерела через вивід VDD або використовувати паразитне живлення від лінії даних.

**4. Скільки ліній необхідно для роботи з DS18B20?**

Для обміну даними використовується одна сигнальна лінія DQ. Також потрібне підключення землі; у режимі зовнішнього живлення додатково використовується VDD.

**5. Для чого призначений протокол 1-Wire та які його особливості?**

Протокол 1-Wire призначений для обміну даними через одну сигнальну лінію. Він працює асинхронно, використовує часові інтервали для передавання бітів і підтримує роботу одного ведучого з декількома веденими пристроями.

**6. Як здійснюється ініціалізація DS18B20?**

Мікроконтролер формує низький рівень на шині приблизно на 480 мкс, після чого відпускає її та перевіряє імпульс присутності від датчика.

**7. Як формуються слоти запису логічних «1» та «0»?**

Для запису «1» мікроконтролер короткочасно утримує лінію на низькому рівні, а потім відпускає її. Для запису «0» лінія утримується на низькому рівні значно довше — приблизно протягом усього часового слота.

**8. Як передати команду DS18B20?**

Спочатку виконується ініціалізація, потім передається команда ROM, наприклад `CCh`, і після неї — функціональна команда, наприклад `4Eh`.

**9. Як почати температурне перетворення DS18B20?**

Після ініціалізації та команди `Skip ROM` передається команда `Convert T` (`44h`). Після цього необхідно дочекатися завершення перетворення.

**10. Як формуються слоти читання DS18B20?**

Мікроконтролер короткочасно встановлює низький рівень, потім відпускає лінію та зчитує її стан у відповідний момент часового слота.

**11. Як зчитати інформацію про температуру з DS18B20?**

Необхідно виконати ініціалізацію, передати `Skip ROM` (`CCh`), запустити перетворення командою `44h`, дочекатися його завершення, повторно ініціалізувати шину, передати `CCh` і `Read Scratchpad` (`BEh`), після чого прочитати два байти температури.

### Висновок

Під час лабораторної роботи розглянуто принцип роботи цифрового датчика температури DS18B20 та особливості інтерфейсу 1-Wire. Розроблено програмний алгоритм ініціалізації шини, передавання команд і запису трьох байтів налаштувань у пам’ять датчика. Для перевірки результату передбачено повторне читання пам’яті DS18B20 у середовищі Proteus.
