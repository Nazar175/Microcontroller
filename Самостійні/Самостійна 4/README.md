# Самостійна робота №4

**Тема:** Організація пам'яті та система адресації мікроконтролерів PIC16

## Контрольні питання до лекції 4

### 1. Розкажіть про карту пам'яті даних мікроконтролерів середнього сімейства PIC.

Пам'ять даних мікроконтролерів середнього сімейства PIC призначена для зберігання змінних, проміжних результатів обчислень та інформації, необхідної для роботи програми.

У мікроконтролерах PIC16 використовується регістрова організація пам'яті даних. Вона поділяється на декілька основних частин:

- **SFR (Special Function Registers)** — спеціальні функціональні регістри, які керують роботою процесора та периферійних пристроїв.
- **GPR (General Purpose Registers)** — регістри загального призначення, які використовуються для зберігання змінних та даних програми.

Пам'ять даних може бути поділена на окремі банки. Перемикання між ними здійснюється за допомогою спеціальних бітів регістра STATUS.

Наприклад, у мікроконтролері PIC16F84A є два банки пам'яті даних, а для зберігання інформації загального призначення доступно 68 байтів оперативної пам'яті.

Окремо в PIC16F84A передбачена EEPROM-пам'ять, яка дозволяє зберігати дані навіть після вимкнення живлення.

### 2. Яке призначення регістрів?

Регістри — це невеликі ділянки пам'яті всередині мікроконтролера, які використовуються для зберігання інформації та керування його роботою.

Вони забезпечують швидкий доступ до даних, необхідних для виконання команд програми.

Основні призначення регістрів:
- зберігання проміжних результатів обчислень;
- зберігання змінних програми;
- керування роботою периферійних пристроїв;
- зберігання інформації про стан процесора;
- керування введенням і виведенням даних;
- забезпечення обміну інформацією між окремими блоками мікроконтролера.

Регістри поділяються на спеціальні регістри (SFR) та регістри загального призначення (GPR).

### 3. Для чого призначені РЗП?

РЗП (регістри загального призначення) призначені для тимчасового зберігання даних, змінних та проміжних результатів виконання програми.

Вони використовуються процесором під час обчислень та обробки інформації.

Основні функції РЗП:
- зберігання значень змінних;
- зберігання проміжних результатів арифметичних операцій;
- збереження даних, отриманих від зовнішніх пристроїв;
- передавання інформації для подальшої обробки;
- використання як робочої пам'яті програми.

У мікроконтролері PIC16F84A для регістрів загального призначення виділено 68 байтів оперативної пам'яті. Вони доступні програмі для запису та читання даних.

### 4. Які спеціальні регістри застосовуються PIC16F84A?

У мікроконтролері PIC16F84A використовуються спеціальні функціональні регістри (SFR), які забезпечують керування процесором, пам'яттю та периферійними пристроями.

Основні спеціальні регістри:

| Назва регістра | Призначення |
|---|---|
| INDF | Забезпечує непряму адресацію пам'яті. |
| TMR0 | Таймер/лічильник для підрахунку імпульсів. |
| PCL | Молодший байт лічильника команд. |
| STATUS | Зберігає прапорці стану процесора та біти вибору банку пам'яті. |
| FSR | Використовується для непрямої адресації пам'яті. |
| PORTA | Керує введенням та виведенням сигналів порту A. |
| PORTB | Керує введенням та виведенням сигналів порту B. |
| EEDATA | Містить дані для роботи з EEPROM. |
| EEADR | Містить адресу комірки EEPROM. |
| PCLATH | Використовується для формування старших бітів адреси переходу. |
| INTCON | Керує перериваннями та містить відповідні прапорці. |
| OPTION_REG | Налаштовує параметри таймера TMR0 та підтягувальні резистори PORTB. |
| TRISA | Визначає напрямок роботи виводів порту A. |
| TRISB | Визначає напрямок роботи виводів порту B. |
| EECON1 | Керує операціями читання та запису EEPROM. |
| EECON2 | Використовується для спеціальної послідовності запису в EEPROM. |

Ці регістри дозволяють програмно налаштовувати роботу мікроконтролера та керувати його основними функціями.

### 5. Для чого використовується регістр W?

Регістр W (Working Register) — це робочий регістр мікроконтролера, який використовується для тимчасового зберігання даних під час виконання команд.

Він має розрядність 8 біт і є одним із головних елементів процесора PIC16.

Основні функції регістра W:
- зберігання операндів перед виконанням арифметичних операцій;
- зберігання результатів обчислень;
- передавання даних між регістрами;
- виконання логічних операцій;
- використання як проміжного сховища інформації.

Наприклад, під час додавання двох чисел одне значення може знаходитися в регістрі W, а інше — в іншому регістрі пам'яті. Після виконання операції результат записується в W або в інший регістр.

Отже, регістр W забезпечує виконання більшості операцій обробки даних у мікроконтролері.

### 6. Скільки блоків пам'яті мікроконтролерів?

У мікроконтролерах PIC використовується гарвардська архітектура, яка передбачає розділення пам'яті програм і пам'яті даних.

Основними блоками пам'яті є:

1. **Пам'ять програм (Program Memory)** — зберігає команди програми, які виконує процесор. У PIC16F84A використовується Flash-пам'ять обсягом 1024 слова по 14 біт.
2. **Пам'ять даних (Data Memory)** — зберігає змінні, проміжні результати та спеціальні регістри. Основою є регістрова пам'ять RAM.
3. **EEPROM-пам'ять даних** — призначена для довготривалого зберігання інформації, яка не зникає після вимкнення живлення.

Таким чином, у PIC16F84A можна виділити три основні типи пам'яті: пам'ять програм, оперативну пам'ять даних та EEPROM.

### 7. Якої розрядності регістр-лічильник PC, що обслуговує пам'ять даних?

PC (Program Counter) — це лічильник команд, який зберігає адресу наступної команди, яку повинен виконати процесор.

У мікроконтролерах середнього сімейства PIC16 лічильник команд має розрядність 13 біт.

Він використовується для визначення поточного положення програми в пам'яті програм та забезпечує послідовне виконання команд.

Варто зазначити, що PC обслуговує саме пам'ять програм, а не пам'ять даних. Для доступу до пам'яті даних використовуються інші механізми адресації.

### 8. Який об'єм програмної пам'яті може адресувати лічильник PC?

Оскільки лічильник команд PC має розрядність 13 біт, він теоретично може адресувати:

**2¹³ = 8192 адреси.**

У класичних мікроконтролерах PIC16 кожна адреса відповідає одному 14-бітному слову програми.

Отже, 13-бітний лічильник команд може адресувати до 8192 слів пам'яті програм.

Однак фактичний обсяг пам'яті залежить від конкретної моделі мікроконтролера.

Наприклад, PIC16F84A має 1024 слова Flash-пам'яті програм, тому фактично використовує лише частину адресного простору, доступного лічильнику PC.

### 9. Скільки рівнів має стек?

Стек — це спеціальна область пам'яті, яка використовується для тимчасового зберігання адрес повернення під час виклику підпрограм та обробки переривань.

У мікроконтролері PIC16F84A апаратний стек має **8 рівнів**.

Це означає, що він може одночасно зберігати до восьми адрес повернення.

Стек працює за принципом LIFO (Last In, First Out), тобто остання записана адреса буде першою, яку процесор використає під час повернення.

Стек автоматично обслуговується процесором і не доступний як звичайна пам'ять даних.

### 10. Що відбувається зі стеком при виконанні команди CALL?

Команда CALL використовується для виклику підпрограми, розташованої за певною адресою в пам'яті програм.

Під час виконання цієї команди відбуваються такі дії:

1. Адреса наступної після CALL команди зберігається у верхній частині апаратного стеку.
2. Лічильник команд PC отримує адресу викликаної підпрограми.
3. Процесор переходить до виконання команд підпрограми.
4. Після виконання команди RETURN процесор отримує зі стеку збережену адресу та продовжує виконання основної програми.

Таким чином, стек дозволяє мікроконтролеру запам'ятовувати місце повернення після виконання підпрограм.

Якщо кількість вкладених викликів перевищує вісім рівнів, виникає переповнення стеку, через що адреси повернення можуть бути втрачені.

### 11. Як формується адреса при виконанні команди GOTO?

Команда GOTO використовується для безумовного переходу до іншої адреси пам'яті програм.

У класичних мікроконтролерах PIC16 команда GOTO містить 11-бітне поле адреси переходу.

Повна адреса формується з двох частин:
- молодші 11 біт беруться безпосередньо з команди GOTO;
- старші біти беруться з регістра PCLATH (біти 4 і 3).

Таким чином, формується 13-бітна адреса переходу, яка записується до лічильника команд PC.

Після цього процесор продовжує виконання програми з нової адреси.

### 12. На які області розбити пам'ять даних?

Пам'ять даних мікроконтролерів PIC16 поділяється на дві основні області:

1. **Область спеціальних функціональних регістрів (SFR)** — містить регістри керування процесором, таймерами, портами введення-виведення та іншими периферійними пристроями.
2. **Область регістрів загального призначення (GPR)** — використовується для зберігання змінних, даних та проміжних результатів роботи програми.

У PIC16F84A ці області розташовані в двох банках пам'яті.

Окрім цього, окремо існує EEPROM-пам'ять даних, яка використовується для довготривалого зберігання інформації.

### 13. Як виконується пряма адресація пам'яті даних?

Пряма адресація — це спосіб звернення до комірки пам'яті даних за адресою, яка безпосередньо вказана в команді програми.

Під час виконання команди процесор отримує адресу потрібного регістра з її адресного поля.

У мікроконтролерах PIC16 адреса комірки пам'яті формується з урахуванням номера банку, який визначається відповідними бітами регістра STATUS.

У PIC16F84A для вибору банку використовується біт RP0:
- RP0 = 0 — вибрано банк 0;
- RP0 = 1 — вибрано банк 1.

Після визначення банку процесор звертається до потрібного регістра та виконує операцію читання або запису.

Перевагою прямої адресації є простота використання, оскільки адреса регістра вказується безпосередньо в команді.

### 14. Який механізм непрямої адресації пам'яті даних?

Непряма адресація — це спосіб звернення до пам'яті даних, за якого адреса потрібної комірки зберігається в спеціальному регістрі-вказівнику.

У мікроконтролерах PIC16 для цього використовуються два спеціальні регістри:

- **FSR (File Select Register)** — містить адресу комірки пам'яті, до якої потрібно звернутися.
- **INDF (Indirect Addressing Register)** — використовується для доступу до даних за адресою, яка зберігається у FSR.

Принцип роботи непрямої адресації:

1. У регістр FSR записується адреса потрібної комірки пам'яті.
2. Програма звертається до регістра INDF.
3. Мікроконтролер автоматично використовує адресу з FSR.
4. Виконується читання або запис даних у відповідну комірку пам'яті.

Цей спосіб зручний для роботи з масивами даних, послідовного перегляду комірок пам'яті та обробки великих обсягів інформації.

## Висновок

Під час виконання самостійної роботи було розглянуто організацію пам'яті мікроконтролерів середнього сімейства PIC16 та особливості роботи основних регістрів. Було вивчено призначення регістрів загального призначення, спеціальних функціональних регістрів і робочого регістра W.

Також було розглянуто принцип роботи лічильника команд PC, особливості апаратного стеку та виконання команд CALL і GOTO. Окрему увагу приділено прямій і непрямій адресації пам'яті даних.

Отримані знання дозволяють краще зрозуміти структуру пам'яті мікроконтролерів PIC16, принципи зберігання інформації та механізми виконання команд програми.
