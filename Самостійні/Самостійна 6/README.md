# Самостійна робота №6

**Тема:** Порти введення-виведення мікроконтролерів PIC16

## Контрольні питання до лекції 6

### 1. Які є налаштування портів?

Порти введення-виведення мікроконтролера використовуються для обміну цифровими сигналами із зовнішніми пристроями, такими як кнопки, світлодіоди, датчики та інші електронні компоненти.

Основними налаштуваннями портів є:

1. **Налаштування на введення (Input)** — порт приймає сигнали від зовнішніх пристроїв.
2. **Налаштування на виведення (Output)** — порт формує сигнали для керування зовнішніми пристроями.
3. **Налаштування окремих бітів** — кожен вивід порту може мати власний напрямок роботи, якщо це підтримує конкретний мікроконтролер.
4. **Налаштування підтягувальних резисторів** — використовуються для встановлення логічного рівня на входах, коли до них не підключено активне джерело сигналу.
5. **Налаштування альтернативних функцій** — окремі виводи можуть використовуватися не лише як звичайні цифрові входи та виходи, а й для роботи таймерів, послідовних інтерфейсів та інших периферійних модулів.

У мікроконтролерах PIC16 напрямок роботи портів зазвичай налаштовується за допомогою регістрів TRIS.

Для класичного PIC16F84A значення бітів TRIS визначають напрямок роботи відповідних виводів:
- `1` — вхід;
- `0` — вихід.

### 2. Яке призначення і функціональні особливості портів PIC16?

Порти PIC16 призначені для взаємодії мікроконтролера із зовнішніми електронними пристроями. За їх допомогою можна отримувати інформацію від датчиків, зчитувати натискання кнопок та керувати світлодіодами, двигунами й іншими компонентами.

У мікроконтролері PIC16F84A є два основні порти:

**PORTA:**
- має 5 ліній введення-виведення (RA0–RA4);
- використовується для підключення зовнішніх пристроїв;
- вивід RA4 має особливості роботи та може використовуватися як вхід тактових імпульсів таймера TMR0;
- інші виводи можуть працювати як цифрові входи або виходи.

**PORTB:**
- має 8 ліній введення-виведення (RB0–RB7);
- використовується для підключення кнопок, світлодіодів та інших пристроїв;
- RB0 може використовуватися як зовнішній вхід переривання;
- RB4–RB7 підтримують переривання під час зміни логічного стану;
- має внутрішні підтягувальні резистори, які можна налаштовувати програмно.

Основні функціональні особливості портів:
- можливість програмного налаштування напрямку роботи;
- незалежне керування окремими лініями;
- передавання та приймання цифрових сигналів;
- підтримка додаткових функцій на окремих виводах.

Таким чином, порти введення-виведення є основним засобом взаємодії мікроконтролера із зовнішнім середовищем.

### 3. Які регістри використовуються для керування портами PIC?

Для керування портами введення-виведення мікроконтролерів PIC16 використовуються спеціальні функціональні регістри.

Основні регістри для PIC16F84A:

| Регістр | Призначення |
|---|---|
| PORTA | Зчитування стану входів та встановлення логічних рівнів на виходах порту A. |
| PORTB | Зчитування стану входів та встановлення логічних рівнів на виходах порту B. |
| TRISA | Визначення напрямку роботи кожного виводу порту A. |
| TRISB | Визначення напрямку роботи кожного виводу порту B. |
| OPTION_REG | Налаштування додаткових параметрів, зокрема підтягувальних резисторів PORTB. |

Особливу роль відіграють регістри TRISA та TRISB, оскільки саме вони визначають, чи працюватиме відповідний вивід як вхід або вихід.

Наприклад:

```asm
BSF STATUS, RP0
CLRF TRISB
BCF STATUS, RP0
```

У цьому прикладі:
- `BSF STATUS, RP0` — вибирає банк 1 пам'яті;
- `CLRF TRISB` — налаштовує всі виводи PORTB як виходи;
- `BCF STATUS, RP0` — повертає вибір до банку 0.

Після цього через регістр PORTB можна керувати підключеними до нього пристроями.

### 4. Як відбувається процес модифікації біта порту?

Модифікація біта порту — це зміна логічного стану окремого виводу мікроконтролера без необхідності змінювати стан інших виводів цього порту.

У мікроконтролерах PIC16 для цього використовуються спеціальні команди Асемблера:

- `BSF` — встановлення вибраного біта в логічну одиницю.
- `BCF` — скидання вибраного біта в логічний нуль.
- `BTFSC` — перевірка біта з пропуском наступної команди, якщо біт дорівнює нулю.
- `BTFSS` — перевірка біта з пропуском наступної команди, якщо біт дорівнює одиниці.

Приклад встановлення біта PORTB:

```asm
BSF PORTB, 0
```

Ця команда встановлює нульовий біт порту B у логічну одиницю.

Приклад скидання біта:

```asm
BCF PORTB, 0
```

Ця команда встановлює нульовий біт порту B у логічний нуль.

Важливо враховувати, що в класичних PIC16F84A операції з окремими бітами порту використовують механізм читання, модифікації та запису (Read-Modify-Write). Тому під час роботи з навантаженням на виходах необхідно враховувати можливі особливості зчитування фактичного стану виводів.

Для надійного керування виходами часто використовують програмну копію значення порту в окремому регістрі, змінюють потрібний біт у цій копії та записують отримане значення в PORTA або PORTB.

Таким чином, модифікація окремих бітів дозволяє зручно керувати підключеними пристроями та виконувати потрібні операції без зміни стану інших ліній порту.
