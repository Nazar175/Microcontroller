# Самостійна робота №20

**Тема:** Архітектура та особливості мікроконтролера ATmega32A сімейства AVR

## Контрольні питання до лекції 20

### 1. Особливості мікроконтролера ATmega32A.

ATmega32A — це 8-бітний мікроконтролер сімейства AVR, розроблений компанією Atmel (нині Microchip Technology). Він призначений для використання в системах автоматизації, керування електронними пристроями та обробки цифрових сигналів.

Основні характеристики ATmega32A:

- 8-бітне процесорне ядро AVR.
- Тактова частота до 16 МГц.
- 32 КБ Flash-пам'яті для зберігання програм.
- 2 КБ SRAM для тимчасового зберігання даних.
- 1 КБ EEPROM для довготривалого зберігання інформації.
- 32 програмовані лінії введення-виведення.
- Три таймери/лічильники.
- Вбудований 10-бітний аналого-цифровий перетворювач (АЦП).
- Підтримка зовнішніх і внутрішніх переривань.
- Послідовні інтерфейси SPI, USART та TWI (I²C).
- Вбудований сторожовий таймер (Watchdog Timer).

Мікроконтролер має низьке енергоспоживання та підтримує різні режими сну, що дозволяє використовувати його в пристроях з автономним живленням.

ATmega32A широко застосовується в системах керування двигунами, побутовій електроніці, вимірювальних приладах, системах сигналізації та навчальних проєктах.

### 2. Призначення вузлів структурної схеми ядра AVR.

Ядро AVR складається з декількох основних функціональних вузлів, які забезпечують виконання команд, обробку даних та керування роботою мікроконтролера.

Основні вузли ядра:

1. **Арифметико-логічний пристрій (АЛП)** — виконує арифметичні операції (додавання, віднімання) та логічні операції (AND, OR, XOR та інші).

2. **Регістровий файл** — містить 32 регістри загального призначення, які використовуються для зберігання операндів та результатів обчислень. Це забезпечує швидку обробку інформації.

3. **Лічильник команд (PC)** — зберігає адресу наступної команди, яку повинен виконати процесор.

4. **Декодер команд** — аналізує отриману команду та визначає, які дії потрібно виконати процесору.

5. **Блок керування** — координує роботу всіх вузлів мікроконтролера та забезпечує правильну послідовність виконання команд.

6. **Стековий покажчик (SP)** — вказує на поточне положення вершини стеку, який використовується для збереження адрес повернення та тимчасових даних.

7. **Регістр стану SREG** — містить прапорці, які відображають результат виконання операцій. Наприклад, прапорці нуля, перенесення, переповнення та знак результату.

8. **Тактова система** — забезпечує синхронізацію роботи процесора та інших внутрішніх пристроїв.

Усі ці вузли працюють разом, забезпечуючи виконання програм і керування периферійними пристроями.

### 3. Особливості організації адресного простору.

Мікроконтролери AVR використовують гарвардську архітектуру, у якій пам'ять програм і пам'ять даних фізично розділені. Це дозволяє процесору одночасно отримувати команди та працювати з даними.

В ATmega32A адресний простір поділяється на три основні види пам'яті:

**1. Пам'ять програм (Flash)**

Призначена для зберігання програмного коду. Її обсяг в ATmega32A становить 32 КБ. Пам'ять є енергонезалежною, тому інформація зберігається навіть після вимкнення живлення.

**2. Оперативна пам'ять (SRAM)**

Використовується для тимчасового зберігання змінних, проміжних результатів обчислень та даних під час виконання програми. Обсяг SRAM становить 2 КБ.

**3. Енергонезалежна пам'ять (EEPROM)**

Призначена для зберігання даних, які повинні залишатися після вимкнення живлення. В ATmega32A її обсяг становить 1 КБ. Вона може використовуватися для зберігання налаштувань пристрою, параметрів роботи та інших важливих даних.

Крім цього, до адресного простору даних належать регістри введення-виведення та регістри загального призначення.

Основні особливості організації пам'яті AVR:
- розділення пам'яті програм і даних;
- наявність окремої оперативної та енергонезалежної пам'яті;
- використання регістрів загального призначення для швидкої обробки інформації;
- можливість доступу до периферійних пристроїв через спеціальні регістри;
- підтримка різних способів адресації пам'яті.

Така організація забезпечує ефективну роботу мікроконтролера та дозволяє використовувати його ресурси для виконання різноманітних завдань.

### 4. Особливості будови портів мікроконтролера AVR.

Порти введення-виведення мікроконтролерів AVR призначені для обміну цифровими сигналами із зовнішніми пристроями. За допомогою портів можна підключати кнопки, світлодіоди, датчики, дисплеї та інші електронні компоненти.

Мікроконтролер ATmega32A має 32 лінії введення-виведення, які об'єднані у чотири 8-бітні порти:

- **PORTA** — 8 ліній (PA0–PA7).
- **PORTB** — 8 ліній (PB0–PB7).
- **PORTC** — 8 ліній (PC0–PC7).
- **PORTD** — 8 ліній (PD0–PD7).

Кожен порт має три основні регістри керування:

1. **DDRx (Data Direction Register)** — визначає напрямок роботи кожного виводу. Значення 0 означає вхід, а 1 — вихід.
2. **PORTx** — використовується для встановлення вихідного логічного рівня або ввімкнення внутрішнього підтягувального резистора, якщо вивід налаштований як вхід.
3. **PINx** — використовується для зчитування фактичного логічного стану виводів порту.

Наприклад, щоб налаштувати всі виводи PORTB як виходи, потрібно записати одиниці в регістр DDRB:

```c
DDRB = 0xFF;
```

Щоб встановити логічну одиницю на всіх виводах порту B:

```c
PORTB = 0xFF;
```

А для зчитування стану входів використовується команда:

```c
unsigned char data = PINB;
```

Крім звичайних функцій введення-виведення, деякі виводи портів мають альтернативні функції. Наприклад, вони можуть використовуватися для роботи з таймерами, перериваннями, АЦП та послідовними інтерфейсами.

Отже, порти AVR є універсальними засобами взаємодії мікроконтролера із зовнішніми пристроями та забезпечують гнучке налаштування кожного виводу.

Під час виконання самостійної роботи було розглянуто основні характеристики мікроконтролера ATmega32A та особливості архітектури сімейства AVR. Було вивчено призначення основних вузлів процесорного ядра, зокрема арифметико-логічного пристрою, регістрового файлу, лічильника команд і блоку керування.
