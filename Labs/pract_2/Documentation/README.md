# Практична робота № 2
## Робота з портами введення та виведення мікроконтролера PIC16F84A

### Мета роботи

Навчитися працювати з портами та регістрами введення/виведення мікроконтролера PIC16F84A, вивчити їхні функції та призначення, а також навчитися налаштовувати порти, зчитувати сигнали з кнопок і керувати вихідними пристроями.

### Завдання роботи

1. Вивчити призначення регістрів TRISA, TRISB, PORTA та PORTB.
2. Налаштувати порт A для введення інформації.
3. Налаштувати порт B для виведення інформації.
4. Реалізувати опитування стану кнопки, підключеної до входу RA1.
5. Забезпечити виведення різних комбінацій сигналів через порт B залежно від стану кнопки.

### Теоретичні відомості

Мікроконтролер PIC16F84A має два основні порти введення/виведення: PORTA та PORTB.

**PORTA** — п'ятибітний порт, який містить п'ять ліній RA0–RA4. Він може використовуватися для отримання сигналів від зовнішніх пристроїв, наприклад кнопок.

**PORTB** — восьмибітний порт, який містить вісім ліній RB0–RB7. Він використовується для передавання сигналів до зовнішніх пристроїв, наприклад світлодіодів.

Для налаштування напрямку роботи портів застосовуються такі регістри:

- **TRISA** — визначає напрямок роботи ліній порту A.
- **TRISB** — визначає напрямок роботи ліній порту B.
- **PORTA** — дає змогу зчитувати стан входів порту A.
- **PORTB** — використовується для керування вихідними сигналами порту B.

Для регістрів TRISA та TRISB значення біта `1` означає введення, а значення `0` — виведення. Наприклад, запис `TRISB = 0b00000000` налаштовує всі лінії порту B на виведення.

Кнопка у розглянутій схемі підключається таким чином, що при її натисканні на вході RA1 встановлюється логічний нуль, а при відпусканні — логічна одиниця завдяки підтягувальному резистору.

### Хід виконання роботи

#### Налаштування портів

На початку програми підключено заголовний файл `pic.h`, який містить визначення для роботи з мікроконтролером, та задано конфігураційні параметри:

```c
#include <pic.h>
CONFIG(FOSC_XT & WDTE_OFF & PWRTE_OFF & CP_OFF);
```

У конфігурації вибрано XT-генератор, вимкнено сторожовий таймер, вимкнено затримку запуску живлення та вимкнено захист коду.

Далі виконано налаштування напрямків роботи портів:

```c
TRISA = 0b11111;
TRISB = 0b00000000;
```

Усі лінії порту A налаштовано як входи, а всі лінії порту B — як виходи.

#### Опитування кнопки

Для постійного перевіряння стану кнопки використовується нескінченний цикл `while (1)`.

Усередині циклу оператор `if` перевіряє значення входу RA1. Якщо значення дорівнює нулю, програма визначає, що кнопку натиснуто. Якщо умова не виконується, програма переходить до блоку `else`.

#### Виведення сигналів

Залежно від стану кнопки на порт B передається відповідна комбінація:

```c
if (RA1 == 0)
{
    PORTB = 0xAA;
}
else
{
    PORTB = 0x99;
}
```

Коли кнопку натиснуто, на порт B передається значення `0xAA`, яке у двійковій системі має вигляд `10101010`.

Коли кнопку відпущено, на порт B передається значення `0x99`, яке у двійковій системі має вигляд `10011001`.

Таким чином, програма реагує на зміну вхідного сигналу та змінює стани виходів мікроконтролера.

### Результати виконання роботи

У результаті розроблено програму мовою C для мікроконтролера PIC16F84A, яка налаштовує порти введення/виведення, постійно перевіряє стан кнопки на вході RA1 та формує відповідні сигнали на порті B.

Очікувані результати роботи програми:

| Стан кнопки | Значення PORTB | Двійкове представлення |
|---|---|---|
| Натиснута | `0xAA` | `10101010` |
| Не натиснута | `0x99` | `10011001` |

Програма демонструє використання регістрів TRISA і TRISB для налаштування портів, зчитування вхідного сигналу та керування виходами за допомогою умовного оператора.

### Відповіді на контрольні питання

**1. Яке призначення і функціональні особливості портів PIC16F84A?**

PIC16F84A має два порти: PORTA на 5 бітів і PORTB на 8 бітів. Вони призначені для обміну цифровими сигналами із зовнішніми пристроями. Напрямок роботи кожної лінії налаштовується окремо за допомогою відповідних бітів регістрів TRISA та TRISB.

**2. Як налаштувати порти для отримання та виведення інформації?**

Для цього використовують регістри TRISA та TRISB. Значення біта `1` налаштовує відповідну лінію на введення, а `0` — на виведення. Наприклад, `TRISA = 0b11111` налаштовує порт A на введення, а `TRISB = 0x00` — порт B на виведення.

**3. Як відбувається процес модифікації біта порту?**

Модифікація біта полягає у зміні його логічного значення з нуля на одиницю або навпаки. В асемблері для роботи з окремими бітами використовують, зокрема, команди BSF і BCF. У мові C можна звертатися до окремих бітів за їхніми іменами, наприклад `RB5 = 1` або `RB5 = 0`.

**4. Як підключити до мікроконтролера світлодіод?**

Світлодіод можна підключити між виходом порту та землею або між живленням і виходом порту. У першому випадку він зазвичай світиться при логічній одиниці на виході, а в другому — при логічному нулі. Підключення необхідно виконувати з урахуванням полярності світлодіода.

**5. Для чого у схемі підключення світлодіодів використовуються обмежувальні резистори?**

Обмежувальні резистори зменшують струм, що проходить через світлодіод. Це захищає світлодіод і вихідний каскад мікроконтролера від пошкодження через надмірний струм.

**6. Для чого використовуються незалежні модулі?**

Незалежні модулі дають змогу розділяти програму на окремі частини, кожна з яких відповідає за певні функції. Це полегшує повторне використання коду, його підтримку та налагодження.

**7. Як здійснюється підключення сторонніх модулів до проєкту?**

Для підключення модуля зазвичай використовують файл реалізації `.c` та заголовний файл `.h`. Файли додають до проєкту, а в програмних файлах, де потрібні функції або типи модуля, підключають його заголовний файл за допомогою директиви `#include`.

Під час виконання практичної роботи розглянуто призначення портів PORTA і PORTB мікроконтролера PIC16F84A, а також регістрів TRISA та TRISB, які визначають напрямок передавання даних.
