# Самостійна робота №13

**Тема: Послідовний обмін даними. Модуль USART (UART)**

## Відповіді на контрольні питання

**1. Що таке UART, у яких режимах може працювати?**

UART (Universal Asynchronous Receiver-Transmitter) — це універсальний асинхронний приймач-передавач, який використовується для послідовного обміну даними між мікроконтролером та іншими пристроями.

Модуль USART може працювати у двох основних режимах:
- **Асинхронний режим (UART)** — передавання даних без окремого тактового сигналу. Синхронізація відбувається за допомогою стартового та стопового бітів.
- **Синхронний режим** — передавання даних із використанням окремого тактового сигналу, який допомагає узгоджувати роботу передавача та приймача.

**2. Які регістри використовуються для роботи модуля USART?**

Для роботи модуля USART у мікроконтролерах PIC16 використовуються такі основні регістри:

- **TXSTA** — регістр стану та керування передавачем. Містить біти налаштування режиму роботи, швидкості передавання та керування передаванням.
- **RCSTA** — регістр стану та керування приймачем. Відповідає за ввімкнення приймача, визначення помилок та налаштування режиму роботи.
- **SPBRG** — регістр генератора швидкості обміну. Визначає швидкість передавання та приймання даних.
- **TXREG** — буферний регістр передавача, у який записуються дані для відправлення.
- **RCREG** — буферний регістр приймача, з якого зчитуються отримані дані.

У деяких моделях PIC16 також використовуються додаткові регістри, наприклад SPBRGH або BAUDCON, тому точний набір залежить від конкретного мікроконтролера.

**3. Які особливості асинхронного обміну даними?**

Асинхронний обмін даними відбувається без використання спільного тактового сигналу між передавачем і приймачем. Для передавання інформації використовуються окремі біти, які допомагають визначити початок і завершення кожної посилки.

Основні особливості:
- Передавання відбувається послідовно, біт за бітом.
- Для початку посилки використовується стартовий біт.
- Після нього передаються біти даних, зазвичай 8 біт.
- За потреби може передаватися біт парності для перевірки помилок.
- Завершується посилка одним або кількома стоповими бітами.
- Передавач і приймач повинні використовувати однакові параметри обміну.

Такий спосіб обміну є простим і не потребує окремої лінії для тактового сигналу.

**4. Яким чином забезпечується однакова швидкість передавача та приймача?**

Однакова швидкість передавача та приймача забезпечується налаштуванням однакової швидкості обміну даними на обох пристроях. Швидкість вимірюється в бодах і визначає кількість переданих символів за секунду.

У мікроконтролерах PIC швидкість обміну задається за допомогою регістра SPBRG, а в деяких моделях також SPBRGH. Значення цих регістрів визначає частоту роботи генератора швидкості USART.

Наприклад, якщо обидва пристрої налаштовані на швидкість 9600 бод, вони зможуть правильно обмінюватися даними за умови однакових параметрів формату посилки.

**5. Як працює UART у режимі асинхронного передавача?**

В асинхронному режимі передавач UART перетворює дані з паралельного вигляду на послідовний і надсилає їх через лінію передачі TX.

Принцип роботи:
1. Програма записує байт даних у регістр TXREG.
2. Дані передаються до внутрішнього зсувного регістра передавача.
3. На лінію TX спочатку надходить стартовий біт із низьким рівнем сигналу.
4. Далі передаються біти даних, починаючи з молодшого біта.
5. Після бітів даних передається стоповий біт із високим рівнем сигналу.
6. Після завершення передавання передавач може прийняти наступний байт.

Для перевірки стану передавача використовуються відповідні біти регістра TXSTA, зокрема TRMT, який показує, чи спорожнів зсувний регістр передавача.

**6. Як працює UART у режимі асинхронного приймача?**

Асинхронний приймач UART отримує послідовні дані через лінію RX та перетворює їх на байт, який можна обробити програмно.

Процес приймання відбувається таким чином:
1. Приймач очікує появи стартового біта на лінії RX.
2. Після його виявлення визначає моменти зчитування бітів даних.
3. Послідовно зчитує всі біти посилки.
4. Перевіряє стоповий біт і, за наявності, біт парності.
5. Отриманий байт записується в регістр RCREG.
6. Програма зчитує дані з RCREG для подальшої обробки.

Для контролю приймання використовуються біти регістра RCSTA. Наприклад, RCIF сигналізує про наявність отриманих даних, а FERR та OERR вказують на помилки формату або переповнення приймача.

**7. Як відбувається розпізнавання стартового імпульсу початку посилки?**

У стані очікування лінія RX зазвичай перебуває у високому логічному рівні. Початок посилки визначається переходом сигналу з високого рівня в низький. Цей перехід означає появу стартового біта.

Після виявлення такого переходу приймач починає відлік часу, щоб зчитувати наступні біти приблизно посередині кожного бітового інтервалу. Це дозволяє зменшити вплив можливих коливань сигналу та правильно визначити значення переданих бітів.

У багатьох реалізаціях USART для точнішого визначення моменту зчитування використовується внутрішня схема передискретизації сигналу.

**8. Як відбувається ініціалізація USART?**

Ініціалізація USART — це початкове налаштування модуля перед початком передавання або приймання даних.

Зазвичай вона виконується в такій послідовності:

1. Налаштувати частоту роботи мікроконтролера, оскільки від неї залежить швидкість обміну.
2. Налаштувати відповідні виводи мікроконтролера: TX як вихід, RX як вхід.
3. Записати потрібне значення швидкості обміну в регістр SPBRG (за потреби також SPBRGH).
4. Налаштувати режим роботи та інші параметри передавача за допомогою регістра TXSTA.
5. Увімкнути приймач і налаштувати його за допомогою регістра RCSTA.
6. За потреби увімкнути переривання для передавання або приймання даних.
7. Після завершення налаштування можна починати обмін інформацією.

Для асинхронного режиму необхідно правильно встановити відповідні біти керування, зокрема SYNC = 0, а також увімкнути модуль USART і потрібні його частини.

Важливо враховувати, що конкретні назви регістрів і послідовність налаштування можуть відрізнятися залежно від моделі мікроконтролера PIC16.
