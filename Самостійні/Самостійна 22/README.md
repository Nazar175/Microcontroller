# Самостійна робота №22

**Тема:** Компілятори для AVR, побітові операції та структура програми для мікроконтролерів AVR.

## Контрольні питання до лекції 22

### 1. Порівняння популярних компіляторів для AVR.

Для розробки програм мікроконтролерів сімейства AVR використовуються різні компілятори та середовища програмування. Вони дозволяють писати програми мовами C та C++, перетворювати вихідний код у машинні команди та завантажувати готову програму в пам'ять мікроконтролера.

Найпопулярнішими інструментами для AVR є:

**1. AVR-GCC**

AVR-GCC — це безкоштовний компілятор із відкритим вихідним кодом, який використовується для програмування мікроконтролерів AVR мовою C та C++.

Основні особливості:
- безкоштовне використання;
- підтримка великої кількості мікроконтролерів AVR;
- можливість оптимізації програмного коду;
- сумісність із різними середовищами розробки;
- підтримка стандартних бібліотек C.

**2. Atmel Studio / Microchip Studio**

Це інтегроване середовище розробки, призначене для створення програм для мікроконтролерів AVR та інших пристроїв Microchip.

Основні особливості:
- зручний редактор програмного коду;
- підтримка мов C, C++ та асемблера;
- вбудовані засоби налагодження;
- можливість перегляду регістрів і пам'яті;
- інтеграція з компілятором AVR-GCC.

**3. IAR Embedded Workbench for AVR**

Це професійне середовище розробки, яке містить власний компілятор для мікроконтролерів AVR.

Основні особливості:
- висока ефективність оптимізації коду;
- підтримка мови C та C++;
- розширені засоби налагодження;
- можливість створення програм із невеликим обсягом пам'яті;
- комерційна ліцензія з обмеженнями безкоштовної версії.

**4. CodeVisionAVR**

Це середовище розробки, яке спеціально призначене для програмування мікроконтролерів AVR мовою C.

Основні особливості:
- зручний редактор коду;
- вбудований компілятор C;
- автоматичне створення початкового коду для налаштування периферійних пристроїв;
- підтримка роботи з портами, таймерами, UART та іншими модулями;
- зручне створення програм для початківців.

Порівняння основних компіляторів:

| Компілятор / середовище | Переваги | Особливості |
|---|---|---|
| AVR-GCC | Безкоштовний, гнучкий, відкритий | Потребує налаштування середовища |
| Microchip Studio | Зручний інтерфейс, налагодження | Інтегрує AVR-GCC |
| IAR Embedded Workbench | Потужна оптимізація, професійні засоби | Переважно комерційний |
| CodeVisionAVR | Простота використання, генератор коду | Орієнтований на AVR |

Отже, вибір компілятора залежить від складності проєкту, вимог до програмного забезпечення та досвіду розробника. Для навчання та більшості нескладних проєктів добре підходить AVR-GCC, оскільки він безкоштовний і має широкі можливості.

### 2. Особливості виконання побітових операцій.

Побітові операції — це операції, які виконуються безпосередньо над окремими бітами двійкових чисел. Вони широко використовуються під час програмування мікроконтролерів AVR для керування портами введення-виведення, налаштування регістрів та роботи з периферійними пристроями.

Основними побітовими операціями є:

**1. AND (побітове І)**

Операція виконується за допомогою оператора `&`. Результат дорівнює 1 лише тоді, коли обидва відповідні біти дорівнюють 1.

Приклад:

```c
unsigned char a = 11001100;
unsigned char b = 10101010;
unsigned char result = a & b;
```

Результат: `10001000`.

**2. OR (побітове АБО)**

Виконується за допомогою оператора `|`. Результат дорівнює 1, якщо хоча б один із відповідних бітів дорівнює 1.

Приклад:

```c
unsigned char a = 11001100;
unsigned char b = 10101010;
unsigned char result = a | b;
```

Результат: `11101110`.

**3. XOR (виключне АБО)**

Виконується за допомогою оператора `^`. Результат дорівнює 1, якщо відповідні біти відрізняються.

Приклад:

```c
unsigned char a = 11001100;
unsigned char b = 10101010;
unsigned char result = a ^ b;
```

Результат: `01100110`.

**4. NOT (побітове заперечення)**

Виконується за допомогою оператора `~`. Кожен біт змінюється на протилежний: 0 перетворюється на 1, а 1 — на 0.

Приклад:

```c
unsigned char a = 11001100;
unsigned char result = ~a;
```

Результат: `00110011`.

**5. Зсув бітів**

Для зсуву використовуються оператори `<<` та `>>`.

- `<<` — зсув усіх бітів ліворуч.
- `>>` — зсув усіх бітів праворуч.

Наприклад:

```c
unsigned char a = 00001100;
unsigned char left = a << 1;
unsigned char right = a >> 1;
```

Результат:
- Лівий зсув: `00011000`.
- Правий зсув: `00000110`.

Побітові операції часто використовуються для керування окремими виводами мікроконтролера.

Наприклад, щоб встановити третій біт порту B у логічну одиницю:

```c
PORTB |= (1 << PB3);
```

Щоб встановити третій біт у нуль:

```c
PORTB &= ~(1 << PB3);
```

Щоб змінити його стан на протилежний:

```c
PORTB ^= (1 << PB3);
```

Важливою особливістю побітових операцій є те, що вони дозволяють змінювати стан окремих бітів регістра, не впливаючи на інші біти.

Таким чином, побітові операції є необхідним інструментом програмування AVR, оскільки забезпечують ефективне керування апаратними ресурсами мікроконтролера.

### 3. Програма-заготовка для AVR.

Програма-заготовка для AVR — це стандартна структура програмного коду, яка використовується як основа для створення нових програм. Вона містить необхідні підключення бібліотек, налаштування мікроконтролера, оголошення змінних та основну функцію програми.

Заготовка допомагає швидше розпочати розробку та забезпечує правильну організацію програмного коду.

Основні складові програми для AVR:

1. **Підключення бібліотек** — додавання необхідних заголовкових файлів.
2. **Оголошення змінних і констант** — визначення даних, які використовуватимуться в програмі.
3. **Функція `main()`** — головна функція, з якої починається виконання програми.
4. **Ініціалізація пристроїв** — налаштування портів, таймерів та інших периферійних модулів.
5. **Основний цикл `while(1)`** — постійне виконання основних команд програми.

Приклад простої програми-заготовки для AVR:

```c
#include <avr/io.h>
#include <util/delay.h>

#define F_CPU 16000000UL

int main(void)
{
    // Налаштування порту B як виходу
    DDRB = 0xFF;

    // Основний цикл програми
    while (1)
    {
        // Увімкнення світлодіодів
        PORTB = 0xFF;

        // Затримка 500 мс
        _delay_ms(500);

        // Вимкнення світлодіодів
        PORTB = 0x00;

        // Затримка 500 мс
        _delay_ms(500);
    }

    return 0;
}
```

У цьому прикладі:
- `#include <avr/io.h>` — підключає бібліотеку для роботи з регістрами мікроконтролера AVR.
- `#include <util/delay.h>` — підключає функції для створення затримок.
- `F_CPU` — визначає тактову частоту мікроконтролера для розрахунку затримок.
- `DDRB = 0xFF` — налаштовує всі виводи порту B як виходи.
- `PORTB = 0xFF` — встановлює логічну одиницю на всіх виводах порту B.
- `PORTB = 0x00` — встановлює логічний нуль на всіх виводах порту B.
- `while(1)` — забезпечує постійне повторення команд.

У результаті підключені до порту B світлодіоди почергово вмикатимуться та вимикатимуться з інтервалом 500 мілісекунд (за умови правильного підключення).

Важливо зазначити, що наведена програма є прикладом для мікроконтролерів AVR із відповідним портом B та тактовою частотою 16 МГц. Конкретні налаштування можуть відрізнятися залежно від моделі мікроконтролера.
