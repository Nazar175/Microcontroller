# Самостійна робота №16

**Тема: Модуль MSSP та режим обміну даними I²C**

## Відповіді на контрольні питання

**1. Для чого призначений модуль MSSP?**

MSSP (Master Synchronous Serial Port) — це модуль мікроконтролера, призначений для послідовного синхронного обміну даними з іншими електронними пристроями.

Він дозволяє мікроконтролеру обмінюватися інформацією з різними периферійними пристроями, наприклад датчиками, мікросхемами пам'яті, дисплеями та іншими контролерами.

Модуль MSSP підтримує два основні протоколи:
- **SPI** — послідовний периферійний інтерфейс.
- **I²C** — двопровідний послідовний інтерфейс.

Завдяки цьому модулю не потрібно реалізовувати весь процес обміну даними програмно, оскільки основні операції виконує апаратна частина мікроконтролера.

**2. Особливості режиму I²C?**

I²C (Inter-Integrated Circuit) — це синхронний послідовний протокол обміну даними, який використовується для зв'язку між мікроконтролером та різними периферійними пристроями.

Основними особливостями I²C є:

- Для обміну даними використовуються дві лінії: SDA (лінія даних) та SCL (лінія тактового сигналу).
- До однієї шини можна підключити декілька пристроїв.
- Кожен пристрій має власну адресу, за якою його можна вибрати для обміну.
- Обмін відбувається синхронно, тобто передавання даних узгоджується з тактовими імпульсами.
- Підтримується робота в режимах ведучого (Master) та веденого (Slave).
- Лінії SDA і SCL зазвичай використовують підтягувальні резистори, оскільки виходи пристроїв мають тип відкритого стоку або відкритого колектора.

Під час передавання даних інформація надсилається пакетами по 8 бітів, після яких приймач формує підтвердження отримання (ACK) або сигнал відсутності підтвердження (NACK).

**3. Як здійснюється формування старт-біту і стоп-біту?**

У протоколі I²C початок і завершення передавання даних визначаються спеціальними умовами на лініях SDA та SCL.

- **Старт-біт (START)** формується тоді, коли лінія SDA переходить із високого рівня в низький, поки лінія SCL залишається у високому стані. Він повідомляє всі пристрої на шині про початок обміну.
- **Стоп-біт (STOP)** формується тоді, коли лінія SDA переходить із низького рівня у високий, поки SCL перебуває у високому стані. Він сигналізує про завершення обміну.

Після формування старт-біта ведучий пристрій може передавати адресу потрібного пристрою та дані. Після стоп-біта шина звільняється і може використовуватися для наступного обміну.

**4. Які регістри використовуються для забезпечення роботи модуля SSP в режимі I²C?**

Для роботи модуля MSSP/SSP у режимі I²C у мікроконтролерах PIC16 використовуються такі основні регістри:

- **SSPCON** — регістр керування модулем. Визначає режим роботи, керує ввімкненням модуля та містить біти стану й керування.
- **SSPCON2** — додатковий регістр керування. Використовується для формування START, STOP, повторного START, а також для керування підтвердженням ACK/NACK.
- **SSPSTAT** — регістр стану. Містить інформацію про поточний стан шини, тип операції та стан приймання або передавання даних.
- **SSPBUF** — буферний регістр, через який передаються та приймаються дані.
- **SSPSR** — зсувний регістр, який забезпечує послідовне передавання та приймання бітів.
- **SSPADD** — регістр адреси. У режимі веденого пристрою зберігає його адресу, а в режимі ведучого використовується для налаштування частоти тактового сигналу SCL.

У деяких моделях PIC16 можуть бути додаткові регістри або відмінності в їхніх назвах, тому конкретний набір залежить від мікроконтролера.

**5. Поясніть призначення регістра SSP PSR?**

Ймовірно, у запитанні мається на увазі регістр **SSPSTAT** (SSP Status Register), оскільки саме він відповідає за стан роботи модуля SSP.

SSPSTAT — це регістр стану модуля MSSP, який використовується для контролю процесу обміну даними через інтерфейс I²C.

Він містить біти, які показують:
- Чи перебуває шина в режимі START або STOP.
- Чи відбувається передавання або приймання даних.
- Чи отримано байт даних.
- Чи відбулася адресація пристрою.
- Який режим роботи модуля вибрано.

Наприклад, біти BF та R/W допомагають визначити стан буфера та напрямок передавання даних, а біти S і P відображають виявлення умов START і STOP.

Отже, SSPSTAT дозволяє програмі контролювати стан модуля та правильно організовувати обмін інформацією між мікроконтролером і периферійними пристроями.

## Висновок

Під час виконання самостійної роботи було розглянуто призначення модуля MSSP та особливості його роботи з протоколом I²C. Було з'ясовано, що цей модуль підтримує послідовний обмін даними з периферійними пристроями, використовуючи дві лінії — SDA та SCL. Також було розглянуто формування стартового і стопового сигналів, призначення основних регістрів SSP та їхню роль у керуванні обміном даними. Отримані знання допомагають зрозуміти принцип роботи інтерфейсу I²C та його використання в мікроконтролерних системах.
