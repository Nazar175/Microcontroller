# Самостійна робота №17

**Тема: Годинник реального часу DS1307 та обмін даними за протоколом I²C**

## Відповіді на контрольні питання

**1. Для чого призначений DS1307?**

DS1307 — це мікросхема годинника реального часу (RTC), яка призначена для відстеження та збереження поточного часу й дати.

Вона дозволяє визначати секунди, хвилини, години, день тижня, число, місяць і рік. Обмін даними з мікроконтролером відбувається через послідовний інтерфейс I²C.

Мікросхема має окреме резервне живлення від батарейки, завдяки чому продовжує відраховувати час навіть після вимкнення основного живлення пристрою.

DS1307 використовується в електронних годинниках, календарях, системах автоматизації, реєстраторах подій та інших пристроях, де потрібно зберігати точний час.

**2. Які основні вузли DS1307?**

Мікросхема DS1307 складається з таких основних функціональних вузлів:

- **Лічильник часу та календаря** — відстежує секунди, хвилини, години, день тижня, дату, місяць і рік.
- **Регістри часу та дати** — зберігають поточні значення часу й календаря.
- **Інтерфейс I²C** — забезпечує обмін даними з мікроконтролером.
- **Генератор тактових імпульсів** — працює разом із зовнішнім кварцовим резонатором частотою 32,768 кГц.
- **Схема резервного живлення** — автоматично перемикає живлення на батарейку, коли основне живлення відсутнє.
- **Оперативна пам'ять RAM обсягом 56 байтів** — використовується для збереження додаткових даних.
- **Вихід SQW/OUT** — може формувати прямокутний сигнал із вибраною частотою або працювати як звичайний вихід.

**3. Скільки ліній необхідно для роботи з DS1307?**

Для обміну даними з DS1307 через інтерфейс I²C необхідно дві сигнальні лінії:

- **SDA** — лінія послідовного передавання даних.
- **SCL** — лінія тактового сигналу.

Крім них, для повноцінної роботи мікросхеми потрібні лінії живлення VCC та GND, а також підключення резервної батарейки до виводу VBAT.

Отже, для обміну даними достатньо двох сигнальних ліній, а для роботи всієї мікросхеми потрібне додаткове підключення живлення.

**4. Які особливості протоколу обміну I²C?**

I²C (Inter-Integrated Circuit) — це синхронний послідовний протокол, який використовується для обміну інформацією між мікроконтролерами та периферійними пристроями.

Основні особливості протоколу:
- Для обміну використовуються дві лінії: SDA та SCL.
- До однієї шини можна підключити декілька пристроїв.
- Кожен пристрій має власну адресу.
- Обмін відбувається синхронно за допомогою тактових імпульсів.
- Один пристрій виступає ведучим (Master), а інші можуть працювати як ведені (Slave).
- Передавання даних відбувається байтами по 8 бітів.
- Після кожного байта приймач передає підтвердження ACK або відсутність підтвердження NACK.
- Для стабільної роботи ліній SDA і SCL використовуються підтягувальні резистори.

Цей протокол зручний тим, що дозволяє підключати багато периферійних пристроїв, використовуючи лише дві сигнальні лінії.

**5. Як здійснюється звертання до DS1307?**

Звертання до DS1307 відбувається через інтерфейс I²C. Мікросхема має фіксовану 7-бітну адресу `0x68`.

Послідовність звертання така:

1. Мікроконтролер формує сигнал START на шині I²C.
2. Передає адресу DS1307 разом із бітом операції.
3. Для запису використовується адреса з бітом запису (0), а для читання — з бітом читання (1).
4. DS1307 розпізнає свою адресу та надсилає підтвердження ACK.
5. Після цього мікроконтролер може передавати або отримувати дані.
6. Після завершення обміну формується сигнал STOP.

Наприклад, для запису даних передається адреса `0xD0`, а для читання — `0xD1`. Це 8-бітні значення, які утворюються з 7-бітної адреси `0x68` шляхом додавання біта напрямку обміну.

**6. Як реалізується читання даних з DS1307?**

Читання даних із DS1307 виконується через інтерфейс I²C. Для цього мікроконтролер звертається до потрібного регістра мікросхеми та зчитує його вміст.

Послідовність читання:

1. Мікроконтролер формує сигнал START.
2. Передає адресу DS1307 з бітом запису (`0xD0`).
3. Після отримання підтвердження ACK передає адресу потрібного регістра, з якого потрібно прочитати дані.
4. Формує повторний сигнал START (Repeated START).
5. Передає адресу DS1307 з бітом читання (`0xD1`).
6. Після підтвердження ACK зчитує потрібну кількість байтів із мікросхеми.
7. Після кожного отриманого байта мікроконтролер надсилає ACK, якщо потрібно продовжити читання.
8. Після останнього байта надсилає NACK і формує сигнал STOP.

Отримані дані містять інформацію про секунди, хвилини, години, день тижня, дату, місяць і рік.

Важливо, що DS1307 зберігає значення часу та дати у форматі BCD (двійково-десятковий код). Тому після зчитування дані за потреби потрібно перетворити у звичайні десяткові числа.

## Висновок

Під час виконання самостійної роботи було розглянуто призначення та будову мікросхеми DS1307, яка використовується для відстеження часу й дати. Було вивчено особливості її підключення, принцип роботи інтерфейсу I²C, порядок звертання до мікросхеми та зчитування інформації з її регістрів. Також було з'ясовано, що DS1307 має резервне живлення, завдяки якому зберігає відлік часу навіть після вимкнення основного живлення. Отримані знання дозволяють використовувати годинник реального часу в мікроконтролерних системах.
